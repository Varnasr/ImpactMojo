Module 3: Causal Graphs: Confounders, Colliders, and Bad Controls

Module 2 said “control for the right covariates.” Which ones are right? A directed acyclic graph (DAG) answers that visually and without algebra. It also delivers the course's most counter-intuitive lesson: some perfectly sensible-looking controls create bias. Getting the control set wrong is the most common avoidable error in applied evaluation.

Reading a DAG

A DAG is a set of variables (nodes) and arrows (direct causal effects). A path is any route between two nodes ignoring arrow direction. Association flows along a path unless something blocks it. Pearl's rules of d-separation tell you when a path is open:

Three building blocks
Chain  \(A \to B \to C\)
\(B\) is a mediator. The path is open; conditioning on \(B\) blocks it (and removes part of the effect you may want).
Fork  \(A \leftarrow B \to C\)
\(B\) is a common cause (confounder). The path is open; conditioning on \(B\) blocks it — this is the good kind of control.
Collider  \(A \to B \leftarrow C\)
\(B\) is a common effect. The path is blocked by default; conditioning on \(B\) (or its descendant) opens it, creating spurious association.

The Backdoor Criterion

To identify the effect of \(D\) on \(Y\), block every backdoor path (one that starts with an arrow into \(D\)) without opening any collider. A covariate set \(Z\) that does this satisfies the backdoor criterion, and adjusting for \(Z\) recovers the causal effect.

\(W\) (a fork: \(D \leftarrow W \to Y\)) opens a backdoor — adjust for it. \(C\) (a collider: \(D \to C \leftarrow Y\)) is closed — adjusting for it opens a spurious path and biases the estimate.

Bad Controls: When “More Controls” Is Wrong

Two controls look helpful but are not. Colliders: conditioning on a common effect of \(D\) and \(Y\) induces selection bias (the classic “why are talented athletes less academic in the selected sample” illusion). Mediators: conditioning on a variable caused by \(D\) removes the very effect you are measuring (over-control bias). A field example: studying whether a cash transfer (\(D\)) raises child nutrition (\(Y\)) and “controlling for” household food spending — which the transfer itself changes — throws away the mechanism.

The rule. Only adjust for variables determined before treatment that sit on a backdoor path. Never adjust for post-treatment variables. “Kitchen-sink” regressions that dump in every available column routinely include colliders and mediators — more controls is not safer.

Worked example — the same coefficient, three control sets
Control set for effect of training \(D\) on earnings \(Y\)StatusWhat it does
Pre-programme: age, schooling, districtgood (confounders)closes backdoors → identifies
Add: current job sector (post-training)mediatorremoves part of the effect
Add: “selected into a follow-up survey”collideropens spurious path → bias

Same data, same \(D\) and \(Y\); the estimate is trustworthy only with the first set. The choice is dictated by the graph, not by which controls improve fit.

In Code: Let the Graph Choose the Controls

## R — encode the DAG and ask which set identifies the effect
library(dagitty)
g <- dagitty('dag {
  D -> Y
  W -> D   W -> Y         // confounder
  D -> C   Y -> C         // collider
}')
adjustmentSets(g, exposure = "D", outcome = "Y")   # returns { W } — not C
isCollider(g, "D", "C", "Y")                        # TRUE

Draw the DAG before you open the data. Pre-registering the graph forces the assumptions into the open and decides the control set in advance — the opposite of fishing for the specification that gives the prettiest coefficient.

Practice
  1. You study whether an NGO's presence (\(D\)) reduces child marriage (\(Y\)). Districts get the NGO partly because of poverty (\(W\)), which also affects marriage. Draw the DAG and state the adjustment set.
    Solution
    \(D \leftarrow W \to Y\) with \(D \to Y\). \(W\) is a fork on the backdoor path \(D \leftarrow W \to Y\); adjust for \(W\) (poverty) and the effect is identified, assuming no other open backdoor. Nothing post-treatment should enter.
  2. A study of scholarship (\(D\)) on graduation (\(Y\)) controls for “enrolled in year 3.” Why might this be a bad control?
    Solution
    Staying enrolled to year 3 is plausibly caused by the scholarship and also predicts graduation — a mediator on the \(D \to \text{enrolment} \to Y\) chain. Conditioning on it removes the part of the effect that runs through retention, understating impact (over-control bias).
  3. Explain the “collider” intuition behind the finding that, among hospital patients, two unrelated diseases appear negatively correlated.
    Solution
    Admission (the collider) is caused by either disease being severe. Conditioning on “admitted” opens the path between the two diseases: among the admitted, a patient without one disease is likelier to have the other, manufacturing a negative association that does not exist in the population. Sample selection is collider conditioning.
