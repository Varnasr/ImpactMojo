Module 8: Difference-in-Differences

When a programme rolls out to some places (or people) and not others, and you observe outcomes before and after, difference-in-differences (DiD) uses the untreated group's change over time as the counterfactual for the treated group's change. It is the workhorse of policy evaluation — and the design where a recent wave of research has overturned the default way practitioners ran it.

The 2×2 Logic

With one treated group, one comparison group, and two periods, the estimator double-differences:

\[ \widehat{\tau}_{\text{DiD}} \;=\; \big(\bar{Y}^{\,\text{post}}_{T} - \bar{Y}^{\,\text{pre}}_{T}\big) \;-\; \big(\bar{Y}^{\,\text{post}}_{C} - \bar{Y}^{\,\text{pre}}_{C}\big) \]
The first difference removes anything fixed about the treated group; the second removes common time shocks. What survives is the treatment effect — if the two groups would have trended together.
Parallel trends — the whole assumption

DiD identifies the ATT only if, absent treatment, the treated group's outcome would have followed the same trend as the control group's. This is untestable (it concerns a counterfactual trend), but you can build confidence by checking that pre-treatment trends were parallel.

Treated (T) and control (C) trend in parallel before treatment. The dashed line extends the control's trend onto the treated group as its counterfactual; the gap after treatment is the ATT.

The Regression Form — and Its Modern Caveat

With many units and periods, DiD is run as two-way fixed effects (TWFE):

\[ Y_{it} \;=\; \alpha_i \;+\; \lambda_t \;+\; \beta\,D_{it} \;+\; \varepsilon_{it} \]
\(\alpha_i\) absorbs fixed unit differences, \(\lambda_t\) common time shocks; \(\beta\) is the DiD estimate. With a single treatment date this is fine.

Staggered rollouts break plain TWFE. When units are treated at different times and effects vary, TWFE uses already-treated units as controls for later-treated ones, so “forbidden comparisons” can flip the sign (Goodman-Bacon 2021; de Chaisemartin & D'Haultfœuille 2020). Use a modern estimator — Callaway & Sant'Anna (2021), Sun & Abraham (2021), or the did imputation approach — and report an event study.

Worked example — a state rolls out a maternity-benefit scheme

One state introduces a cash maternity benefit; a neighbouring state does not. Institutional-delivery rates (%) before and after:

PrePostChange
Treated state6278+16
Comparison state6069+9
Difference-in-differences+7 pp

Both states improved (a national time trend); the scheme's effect is the extra 7 pp the treated state gained — valid only if, without the scheme, it would have risen by the same 9 pp as its neighbour.

In Code

## R — TWFE for a single date; Callaway–Sant'Anna for staggered rollout
library(fixest)
feols(inst_delivery ~ treat | district + year, cluster = ~district, data = d)
## event study (leads/lags relative to treatment year):
feols(inst_delivery ~ i(rel_year, ref = -1) | district + year, data = d)
## robust to staggered timing + heterogeneous effects:
library(did)
att <- att_gt(yname="inst_delivery", tname="year", idname="district",
              gname="first_treat_year", data = d)
aggte(att, type = "dynamic")     # event-study ATT, bias-free under staggering
* Stata — TWFE, event study, and a heterogeneity-robust estimator
reghdfe inst_delivery treat, absorb(district year) vce(cluster district)
csdid inst_delivery, ivar(district) time(year) gvar(first_treat_year)
estat event        // dynamic ATT / pre-trend leads
Practice
  1. An event-study plot shows the treated and control groups already diverging two years before the policy. What does this imply for the DiD estimate?
    Solution
    A pre-trend means parallel trends is doubtful: the groups were on different trajectories before treatment, so the post-period gap mixes the policy with that ongoing divergence. The DiD estimate is likely biased. Options: find a better comparison group, allow group-specific trends (cautiously), or abandon DiD here.
  2. Why can two-way fixed effects give a negative estimate even when the treatment helped everyone, in a staggered rollout?
    Solution
    TWFE is a weighted average of all 2×2 comparisons, including ones that use already-treated units as controls for later-treated units. If effects grow over time, those forbidden comparisons subtract a large already-treated change, contributing negative weights that can dominate and flip the sign. Heterogeneity-robust estimators avoid the forbidden comparisons.
  3. A reviewer asks you to “prove parallel trends.” What can and cannot be shown?
    Solution
    You cannot prove it — it is a statement about an unobserved counterfactual trend. You can provide supporting evidence: parallel pre-treatment trends (event-study leads near zero), robustness to alternative comparison groups, and placebo tests. State it as an assumption made credible, not proven.
Varna
If your evaluation rests on DiD, draw the event-study plot first and put it on slide one. Funders and sceptics believe a clean pre-trend far more than a single coefficient — and if the pre-trend is ugly, you want to know before you build the whole report on it.
