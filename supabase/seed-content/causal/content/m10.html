Module 10: Causal Machine Learning

The toolkit so far estimates one average effect. Often the question is sharper: for whom does the programme work, and how do we target the next rupee? Machine learning, bent to causal questions, estimates effects that vary across people without overfitting them into noise.

From Average to Heterogeneous Effects

A cash transfer or an input subsidy rarely helps everyone equally. The conditional average treatment effect, CATE, is the effect as a function of characteristics: E[Y(1) − Y(0) | X = x]. Estimating it by hand invites fishing: slice the data enough ways and a spurious subgroup effect always appears.

Two Tools That Discipline the Search
Causal forests
Wager and Athey (2018) adapt random forests to estimate the CATE, with honest sample-splitting so the data used to find subgroups is not the data used to estimate their effects. This guards against the fishing problem.
Double machine learning
Chernozhukov et al. (2018). Use flexible learners for the nuisance parts (the outcome model and the treatment model), then combine them so the treatment-effect estimate stays valid and its confidence interval is honest, even with many covariates.
Key Idea

These methods estimate heterogeneity; they do not create identification. A causal forest on observational data still needs unconfoundedness. The machine learning handles flexibility and many covariates. It does not rescue a design where the selection-bias term is non-zero.

The practitioner payoff is targeting. If a programme’s effect concentrates in a definable group, a causal forest can rank households by predicted benefit, and a budget can be aimed where it does the most good rather than spread evenly. That is the difference between an evaluation that scores a programme and one that improves it.

Honest splitting is the whole point. Finding subgroups and estimating their effects on the same data is the oldest way to manufacture a false positive. The value of causal forests is the discipline, not the flexibility. A subgroup result without out-of-sample validation is a hypothesis, not a finding.
