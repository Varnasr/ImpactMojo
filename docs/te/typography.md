| పాత్ర | ఫాంట్ | బరువులు | ఫాల్‌బ్యాక్ |
|------|------|---------|----------|
| **శీర్షికలు** | Inter | 400, 500, 600, 700, 800 | sans-serif |
| **బాడీ టెక్స్ట్** | Amaranth | 400, 700 | sans-serif |
| **కోడ్ / మోనోస్పేస్** | JetBrains Mono | 400 | monospace |
| **బహుభాషా** | Noto Sans (Devanagari, Bengali, Tamil, Telugu) | 400, 700 | sans-serif |

## Google Fonts లోడింగ్

అన్ని పేజీలు ఒకే Google Fonts URL ద్వారా ఫాంట్‌లను లోడ్ చేస్తాయి:

```html
<link href="https://fonts.googleapis.com/css2?family=Amaranth:wght@400;700&family=Inter:wght@400;500;600;700;800&family=JetBrains+Mono&family=Noto+Sans:wght@400;700&display=swap" rel="stylesheet">
```

## డిజైన్ టోకెన్లు

### ఫాంట్ కుటుంబాలు

```css
--font-heading: 'Inter', sans-serif;
--font-body: 'Amaranth', sans-serif;
--font-mono: 'JetBrains Mono', monospace;
```

| `--text-lg` | 1.125rem | లీడ్ పేరాలు |
| `--text-xl` | 1.25rem | విభాగ శీర్షికలు (h3) |

| `--text-3xl` | 1.875rem | హీరో శీర్షికలు (h1) |

## ఎన్‌కోడింగ్

అన్ని HTML ఫైల్‌లు UTF-8 ఎన్‌కోడింగ్‌ను ఉపయోగిస్తాయి:

```html
<meta charset="UTF-8">
```

ఇది వీటి సరైన రెండరింగ్‌ను నిర్ధారిస్తుంది:
- హిందీ (हिन्दी), బెంగాలీ (বাংলা), తమిళం (தமிழ்), తెలుగు (తెలుగు)
- విద్యా కంటెంట్‌లో ప్రత్యేక అక్షరాలు (em-dashes, smart quotes, మొదలైనవి)
