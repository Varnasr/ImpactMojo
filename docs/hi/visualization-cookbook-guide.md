# Visualization Cookbook गाइड

## Visualization Cookbook क्या है?

Visualization Cookbook एक **प्रश्न-संचालित चार्ट चयन उपकरण** है जिसमें उत्पादन-तैयार Python कोड शामिल है। चार्ट गैलरी ब्राउज़ करने और यह अनुमान लगाने के बजाय कि कौन-सा चार्ट प्रकार आपके डेटा के लिए उपयुक्त है, आप एक सरल प्रश्न का उत्तर देते हैं — "मेरा डेटा कौन-सी कहानी कहता है?" — और आपको सही चार्ट के साथ कार्यशील कोड मिलता है जिसे आप तुरंत कॉपी करके उपयोग कर सकते हैं।

इसमें **14 चार्ट प्रकार** शामिल हैं जो विकास कार्य की सबसे आम डेटा कहानियों को कवर करते हैं।

**एक्सेस:** DevData Practice (Professional tier) का हिस्सा — [Visualization Cookbook खोलें](https://impactmojo-devdata-pro.netlify.app/charts.html)

## यह समस्या जिसका समाधान करता है

विकास पेशेवर डेटा से भरी रिपोर्ट, प्रस्ताव और प्रस्तुतियाँ बनाते हैं — लेकिन चार्ट अक्सर सबसे कमज़ोर हिस्सा होते हैं। आम समस्याएँ:

- **गलत चार्ट प्रकार** — जब बार चार्ट अधिक स्पष्ट होता तब पाई चार्ट का उपयोग करना, या जब आप समय नहीं दिखा रहे तब लाइन चार्ट का उपयोग करना
- **अव्यवस्थित दृश्य** — एक चार्ट पर बहुत सारे रंग, लेबल, या डेटा बिंदु
- **शुरुआत से शुरू करना** — सिर्फ़ एक अच्छा चार्ट बनाने के लिए Excel में घंटों बिताना या Python सीखने की कोशिश करना
- **असंगत गुणवत्ता** — हर टीम सदस्य ऐसे चार्ट बनाता है जो अलग दिखते हैं

Visualization Cookbook इन्हें पहले एक प्रश्न पूछकर हल करता है: **आपका डेटा क्या कहना चाहता है?**

---

## यह कैसे काम करता है

### चरण 1: अपनी डेटा कहानी चुनें

प्रत्येक चार्ट छह प्रकार के प्रश्नों में से एक का उत्तर देता है:

| डेटा कहानी | आप क्या दिखा रहे हैं | उदाहरण |
|-----------|-------------------|---------|
| **तुलना** | चीज़ें एक-दूसरे से कैसे भिन्न हैं | "किस ज़िले में सबसे अधिक टीकाकरण दर है?" |
| **वितरण** | डेटा एक रेंज में कैसे फैला हुआ है | "हमारे लक्षित क्षेत्र में घरेलू आय कैसे वितरित है?" |
| **संबंध** | दो चर एक-दूसरे से कैसे संबंधित हैं | "क्या शिक्षा व्यय और सीखने के परिणामों के बीच कोई सहसंबंध है?" |
| **संरचना** | एक संपूर्ण क्या बनाता है | "हमारे बजट का कितना अनुपात प्रत्येक कार्यक्रम क्षेत्र में जाता है?" |
| **समय श्रृंखला** | समय के साथ कुछ कैसे बदलता है | "पिछले 10 वर्षों में बौनापन प्रसार कैसे बदला है?" |
| **स्थानिक** | भूगोल के अनुसार कुछ कैसे भिन्न होता है | "किन राज्यों में सबसे अधिक गरीबी दर है?" |

### चरण 2: सही चार्ट प्राप्त करें

आपकी डेटा कहानी के आधार पर, Cookbook एक या अधिक चार्ट प्रकारों की सिफ़ारिश करता है और आपको दिखाता है:
- एक **नमूना चार्ट** ताकि आप देख सकें कि यह कैसा दिखता है
- **इसे कब उपयोग करें** — और कब नहीं
- matplotlib और seaborn (मानक डेटा विज्ञान लाइब्रेरी) का उपयोग करते हुए **उत्पादन-तैयार Python कोड**

### चरण 3: कोड को अनुकूलित करें

Python कोड कॉपी करें, नमूना डेटा को अपने डेटा से बदलें, और चलाएँ। चार्ट प्रकाशन-तैयार है — उचित लेबल, स्वच्छ स्वरूपण, और पेशेवर शैली।

## 14 चार्ट प्रकार

| चार्ट | किसके लिए सर्वोत्तम | डेटा कहानी |
|-------|---------|-----------|
| बार चार्ट | श्रेणियों की तुलना करना | तुलना |
| समूहीकृत बार चार्ट | समूहों में श्रेणियों की तुलना करना | तुलना |
| क्षैतिज बार चार्ट | लंबे नामों वाली कई श्रेणियाँ | तुलना |
| लाइन चार्ट | समय के साथ रुझान | समय श्रृंखला |
| क्षेत्र चार्ट | समय के साथ संचयी रुझान | समय श्रृंखला + संरचना |
| स्कैटर प्लॉट | दो चर के बीच संबंध | संबंध |
| बबल चार्ट | तीन-चर संबंध | संबंध |
| हिस्टोग्राम | एकल चर का वितरण | वितरण |
| बॉक्स प्लॉट | समूहों में वितरण की तुलना करना | वितरण |
| पाई / डोनट चार्ट | एक संपूर्ण के हिस्से (कुछ श्रेणियाँ) | संरचना |
| स्टैक्ड बार चार्ट | श्रेणियों में एक संपूर्ण के हिस्से | संरचना |
| हीटमैप | द्वि-आयामी डेटा में पैटर्न | संबंध |
| कोरोप्लेथ मानचित्र | भौगोलिक भिन्नता | स्थानिक |
| स्लोप चार्ट | दो समय बिंदुओं के बीच परिवर्तन | तुलना + समय |

## क्या मुझे Python जानना ज़रूरी है?

**ज़रूरी नहीं।** Cookbook सबसे उपयोगी है यदि आप Python कोड चला सकते हैं (या कोई सहकर्मी जो चला सकता है), लेकिन कोडिंग ज्ञान के बिना भी:

- **चार्ट चयन मार्गदर्शन अपने आप में मूल्यवान है।** कौन-सा चार्ट प्रकार उपयोग करना है यह जानना आधी लड़ाई है — फिर आप इसे Excel, Google Sheets, या किसी भी उपकरण में बना सकते हैं जिसके साथ आप सहज हैं।
- **कोड एनोटेट किया गया है।** टिप्पणियाँ बताती हैं कि प्रत्येक पंक्ति क्या करती है, इसलिए बुनियादी Python कौशल वाला कोई व्यक्ति इसे संशोधित कर सकता है।
- **ImpactMojo के Data & Technology courses बुनियादी बातें सिखाते हैं।** यदि आप डेटा विज़ुअलाइज़ेशन के लिए Python सीखना चाहते हैं, तो Data Visualization foundational course से शुरुआत करें।

## शिक्षक Cookbook का उपयोग कैसे कर सकते हैं

### डेटा विज़ुअलाइज़ेशन कार्यशालाओं के लिए
प्रतिभागियों को "अपनी डेटा कहानी चुनें" ढाँचे के माध्यम से ले जाएँ। उनसे अपना डेटा लाने को कहें और चार्ट प्रकार चुनने से पहले यह पहचानने को कहें कि यह कौन-सी कहानी कहता है।

### रिपोर्ट लेखन सत्रों के लिए
जब टीमें रिपोर्ट तैयार कर रही हों, तो यह सुनिश्चित करने के लिए Cookbook का उपयोग करें कि चार्ट उपयुक्त और स्पष्ट हैं। छह डेटा कहानी श्रेणियाँ टीमों को यह सोचने में मदद करती हैं कि वे क्या संप्रेषित करने का प्रयास कर रहे हैं।

### चार्ट साक्षरता सिखाने के लिए
भले ही प्रतिभागी कोड न लिखें, Cookbook उन्हें चार्ट को आलोचनात्मक रूप से पढ़ना सिखाता है। "यह चार्ट कौन-सी डेटा कहानी कह रहा है? क्या यह उस कहानी के लिए सही चार्ट प्रकार है?"

## सुझाव

- **डेटा कहानी से शुरू करें, चार्ट प्रकार से नहीं।** "मैं एक पाई चार्ट बनाना चाहता हूँ" गलत शुरुआती बिंदु है। "मैं दिखाना चाहता हूँ कि हमारे बजट का कितना अनुपात प्रत्येक कार्यक्रम में जाता है" सही है।
- **कम ज़्यादा है।** सबसे अच्छे चार्ट एक चीज़ को स्पष्ट रूप से संप्रेषित करते हैं। यदि आपके चार्ट को व्याख्या के एक पैराग्राफ की आवश्यकता है, तो इसे सरल बनाएँ।
- **डेटा विज़ुअलाइज़ेशन पर Handout के साथ Cookbook का उपयोग करें।** हैंडआउट सिद्धांतों को कवर करता है; Cookbook कार्यान्वयन प्रदान करता है।
- **Python कोड Google Colab में काम करता है।** यदि आपके पास Python इंस्टॉल नहीं है, तो कोड को [Google Colab](https://colab.research.google.com) में पेस्ट करें — यह मुफ़्त है और आपके ब्राउज़र में चलता है।
