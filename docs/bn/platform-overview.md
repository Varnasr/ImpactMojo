# প্ল্যাটফর্ম পরিচিতি

এই পৃষ্ঠাটি ImpactMojo-তে যা যা পাওয়া যায় তার সবকিছুর মধ্য দিয়ে আপনাকে নিয়ে যায় — প্রতিটি কনটেন্ট ধরন কী, কীভাবে সাজানো হয়েছে, এবং আপনি কীভাবে এটি আপনার কাজে, আপনার শ্রেণিকক্ষে, বা আপনার দলের পেশাগত উন্নয়নে ব্যবহার করতে পারেন।

---

## কোর্সসমূহ

কোর্সগুলো ImpactMojo-র মেরুদণ্ড। দুটি ধরন আছে:

### Flagship কোর্স (১১টি কোর্স)

এগুলো বিস্তৃত, গভীর কোর্স — প্রতিটিতে প্রায় **১৩টি মডিউল** রয়েছে যা একটির উপর আরেকটি গড়ে ওঠে। এগুলোকে এক সেমিস্টার-দীর্ঘ বিশ্ববিদ্যালয় কোর্সের সমতুল্য মনে করুন, তবে কর্মরত পেশাদারদের জন্য লেখা।

প্রতিটি flagship কোর্সে রয়েছে:
- স্পষ্ট সংজ্ঞাসহ ৫০-৬৫টি গুরুত্বপূর্ণ পরিভাষার একটি **lexicon**
- বাস্তব কর্মসূচি থেকে নেওয়া **দক্ষিণ এশীয় case studies**
- উপকরণটিকে আপনার নিজের কাজের সাথে সংযুক্ত করার জন্য **প্রতিফলনমূলক প্রম্পট**
- DevDiscourses থেকে সংকলিত **আরও পড়ার** লিঙ্ক

**উদাহরণ flagship কোর্স:**
- *MEL for Development* — পর্যবেক্ষণ ও মূল্যায়নের মৌলিক বিষয় থেকে অভিযোজনমূলক শেখা পর্যন্ত
- *Theory of Change* — বাস্তব কর্মসূচিতে theories of change তৈরি, যাচাই ও ব্যবহার করা
- *Development Economics* — শুধু অর্থনীতিবিদদের জন্য নয়, উন্নয়ন প্র্যাকটিশনারদের জন্য গুরুত্বপূর্ণ অর্থনৈতিক ধারণা

**কীভাবে ব্যবহার করবেন:** নিজের গতিতে একটি কোর্স সম্পন্ন করুন (সপ্তাহে একটি মডিউল একটি স্বচ্ছন্দ ছন্দ)। একটি পরিকল্পনা সেশনের আগে আপনার দলকে মডিউলগুলো প্রাক-পাঠ হিসেবে নির্ধারণ করুন। একটি বিশ্ববিদ্যালয় কোর্স বা NGO প্রশিক্ষণ কর্মসূচির পাঠ্যক্রমের মেরুদণ্ড হিসেবে এগুলো ব্যবহার করুন।

### ভিত্তিমূলক কোর্স (৩৮টি কোর্স)

ব্যাপক study decks যা একটি নির্দিষ্ট দক্ষতা বা ধারণা গভীরভাবে কভার করে। এগুলো নিজ-গতির পাঠ্য উপকরণ — কভারেজে পুঙ্খানুপুঙ্খ তবে flagship কোর্সের চেয়ে সরল ফরম্যাটে। **৪টি কোর্স এখন native ১০০-slide HTML decks** (Dev Econ, MEL, Climate, Inequality), interactive charts, light/dark theme এবং keyboard/touch নেভিগেশনসহ। বাকি কোর্সগুলো visual Gamma presentations হিসেবে পাওয়া যায়। বিস্তারিত জানতে [101 Course Decks Guide](101-decks-guide.md) দেখুন।

**এগুলোতে যা আছে:**
- ব্যাপক বিষয় কভারেজ — প্রতিটি তার বিষয় পুঙ্খানুপুঙ্খভাবে কভার করে
- নিজ-অধ্যয়ন ফরম্যাট — নিজের গতিতে পড়ুন, কোনো interactive উপাদান নেই
- Native HTML slide decks (৪টি কোর্স) বা Gamma visual presentations (৩৪টি কোর্স), track অনুযায়ী ভারতীয় লোকশিল্পসহ

**এগুলোতে (এখনও) যা নেই:**
- Interactive বৈশিষ্ট্য, quizzes বা মূল্যায়ন
- প্রকল্প বা হাতে-কলমে অনুশীলন
- Interactive lexicons বা AI study companions

**আমরা কোথায় যাচ্ছি:** দীর্ঘমেয়াদী পরিকল্পনা হলো ভিত্তিমূলক কোর্সগুলোকে interactive উপাদান, মূল্যায়ন ও প্রকল্পসহ flagship মানে উন্নীত করা। আপাতত, এগুলো চমৎকার নিজ-অধ্যয়ন ও রেফারেন্স উপকরণ।

**উদাহরণ ভিত্তিমূলক কোর্স:**
- *Survey Design Essentials* — এমন প্রশ্নাবলি ডিজাইন করা যা সত্যিই উপযোগী তথ্য তৈরি করে
- *Introduction to Qualitative Methods* — প্র্যাকটিশনারদের জন্য সাক্ষাৎকার, focus groups এবং coding
- *Understanding WEE (Women's Economic Empowerment)* — frameworks, পরিমাপ ও কর্মসূচি ডিজাইন
- *Data Visualization for Development* — আপনার তথ্যকে সিদ্ধান্তগ্রহণকারীদের বোধগম্য গল্পে রূপান্তর করা

**কীভাবে ব্যবহার করবেন:** নতুন প্রকল্প শুরুর আগে একটি দ্রুত দক্ষতা-নির্মাতা হিসেবে একটি নিন। নতুন দল সদস্যদের নিজ-অধ্যয়ন পাঠ হিসেবে এগুলো নির্ধারণ করুন। একটি কর্মশালার আগে প্রাক-পাঠ হিসেবে ব্যবহার করুন। কোনো বিষয়ে আরও ব্যাপকভাবে যেতে একটি flagship কোর্সের সাথে জোড়া লাগান।

### Learning Tracks

সব কোর্স **৬টি tracks**-এ সাজানো, তাই আপনি আপনার ভূমিকা বা আগ্রহের ভিত্তিতে একটি কাঠামোবদ্ধ শেখার পথ অনুসরণ করতে পারেন:

1. **MEL & Research** — পর্যবেক্ষণ, মূল্যায়ন, গুণগত ও পরিমাণগত পদ্ধতি
2. **Economics & Policy** — উন্নয়ন অর্থনীতি, রাজনৈতিক অর্থনীতি, তহবিল সংগ্রহ
3. **Gender & Equity** — জেন্ডার স্টাডিজ, নারীর অর্থনৈতিক ক্ষমতায়ন, পরিচর্যা অর্থনীতি, data feminism
4. **Governance & Society** — সাংবিধানিক কাঠামো, decolonization, কমিউনিটি উন্নয়ন
5. **Health & Wellbeing** — জনস্বাস্থ্য, জলবায়ু অভিযোজন, সামাজিক-আবেগিক শেখা, জীবিকা
6. **Communication & Data** — তথ্য সাক্ষরতা, visual ethnography, আচরণ পরিবর্তন যোগাযোগ, advocacy

## Interactive Games (১৭টি games)

এগুলো interactive simulations যা আপনাকে অর্থনৈতিক সিদ্ধান্তের চালকের আসনে বসায়। আপনি একটি জেলা স্বাস্থ্য বাজেট বরাদ্দ করতে পারেন, একটি মাইক্রোফাইন্যান্স portfolio পরিচালনা করতে পারেন, বা বাণিজ্য নীতিতে চলাফেরা করতে পারেন — এবং বাস্তব সময়ে আপনার পছন্দের পরিণতি দেখতে পারেন।

প্রতিটি game:
- **আপনার ব্রাউজারে চলে** — কোনো ডাউনলোড নেই, কোনো ইনস্টলেশন নেই
- যেখানে সম্ভব **বাস্তব অর্থনৈতিক প্যারামিটার** ব্যবহার করে — বানানো সংখ্যা নয়
- **ডিব্রিফিংয়ের জন্য ডিজাইন করা** — প্রকৃত শেখা হয় game-এর পরের কথোপকথনে
- **মোবাইলে কাজ করে** — তাই আপনি ক্ষেত্র-ভিত্তিক কর্মশালায় এগুলো ব্যবহার করতে পারেন

**কীভাবে ব্যবহার করবেন:** অনুমান প্রকাশ করতে একটি কর্মশালার শুরুতে একটি game চালান। বিমূর্ত ধারণাকে বাস্তব করতে অর্থনীতি ক্লাসে এগুলো ব্যবহার করুন। একটি দল-গঠন অনুশীলন হিসেবে একটি খেলুন যা একই সাথে উপযোগী কিছু শেখায়।

## Interactive Labs (১৩টি labs)

Labs হলো ব্রাউজার-ভিত্তিক workbenches যেখানে আপনি কিছু তৈরি করেন। কোর্সের বিপরীতে (যেখানে আপনি পড়েন ও প্রতিফলন করেন), labs হাতে-কলমে — আপনি একটি নির্দেশিত workflow অনুসরণ করেন এবং একটি বাস্তব আউটপুট তৈরি করেন।

**উদাহরণ labs:**
- *Theory of Change Builder* — ধাপে ধাপে একটি visual theory of change নির্মাণ করুন
- *Research Question Builder* — একটি অস্পষ্ট ধারণাকে একটি কেন্দ্রীভূত, গবেষণাযোগ্য প্রশ্নে পরিমার্জিত করুন
- *Qualitative Coding Lab* — নির্দেশিত অনুশীলনের সাথে গুণগত তথ্য coding অনুশীলন করুন

প্রতিটি lab:
- প্রক্রিয়ার মধ্য দিয়ে আপনাকে **ধাপে ধাপে** নিয়ে যায়
- একটি **ব্যবহারযোগ্য আউটপুট** তৈরি করে — একটি framework, একটি পরিকল্পনা, একটি ডায়াগ্রাম
- ফলাফল PDF বা PNG হিসেবে **এক্সপোর্ট করতে** পারে (এক্সপোর্ট premium tiers-এ পাওয়া যায়)
- **কোনো সার্ভার বা ইনস্টলেশন প্রয়োজন নেই** — সবকিছু আপনার ব্রাউজারে চলে

**কীভাবে ব্যবহার করবেন:** একটি কর্মশালার ব্যবহারিক উপাদান হিসেবে একটি lab ব্যবহার করুন। শিক্ষার্থীদের একটি অ্যাসাইনমেন্ট হিসেবে একটি lab সম্পন্ন করতে দিন। নিজের কাজ শুরু করতে একটি ব্যবহার করুন — একটি ফাঁকা PowerPoint-এর দিকে তাকিয়ে থাকার পরিবর্তে lab-এ আপনার theory of change তৈরি করুন।

## Handouts (৪০০+)

Handouts হলো একক-পৃষ্ঠার HTML নথি — সংক্ষিপ্ত রেফারেন্স উপকরণ যা আপনি পর্দায় পড়তে, প্রিন্ট করতে বা শেয়ার করতে পারেন। এগুলোকে সুন্দরভাবে ডিজাইন করা cheat sheets ও briefing notes মনে করুন।

এগুলো track অনুযায়ী সাজানো, তাই আপনি MEL, জেন্ডার, অর্থনীতি ইত্যাদি সম্পর্কিত সব handouts ব্রাউজ করতে পারেন।

**কীভাবে ব্যবহার করবেন:** একটি প্রশিক্ষণ সেশনের জন্য একটি সেট প্রিন্ট করুন। একটি দল মিটিংয়ের আগে একটি handout প্রাক-পাঠ হিসেবে শেয়ার করুন। নিয়মিত ব্যবহৃত ধারণার জন্য এগুলো desk references হিসেবে রাখুন। এগুলো শুধু কোর্সের সম্পূরক হিসেবে নয়, নিজেরাই উপযোগী হওয়ার জন্য ডিজাইন করা।

## ImpactLex (৩৯০+ পরিভাষা)

ImpactLex হলো একটি **উন্নয়ন খাতের অভিধান** — স্পষ্ট, প্র্যাকটিশনার-বান্ধব সংজ্ঞাসহ ৩৯০+ পরিভাষা, সূত্র ও case studies-এর একটি অনুসন্ধানযোগ্য, ব্রাউজযোগ্য সংগ্রহ। এটি ImpactMojo-তে [/impactlex/](https://www.impactmojo.in/impactlex/)-এ host করা এবং একটি Progressive Web App (PWA) হিসেবে কাজ করে, যার অর্থ:

- একবার লোড করার পর এটি **অফলাইনে কাজ করে** — নির্ভরযোগ্য ইন্টারনেট ছাড়া ক্ষেত্রে থাকাকালীন উপযোগী
- আপনি এটিকে একটি সাধারণ app-এর মতো আপনার **ফোনের হোম স্ক্রিনে যোগ করতে** পারেন
- এটি **অনুসন্ধানযোগ্য** — একটি পরিভাষা, সংক্ষিপ্ত রূপ বা ধারণা টাইপ করুন এবং তাৎক্ষণিকভাবে খুঁজুন
- প্রতিটি পরিভাষার একটি **শেয়ারযোগ্য URL** আছে — একটি কর্মশালা chat বা প্রতিবেদনে লিঙ্কটি দিন

**উদাহরণ এন্ট্রি:** Attribution, Beneficiary Feedback Mechanism, Counterfactual, Disaggregated Data, Evaluability Assessment... Zero-Based Budgeting পর্যন্ত।

**কীভাবে ব্যবহার করবেন:** আপনার ফোনে একটি দ্রুত রেফারেন্স হিসেবে রাখুন। খাত পরিভাষা শিখছেন এমন নতুন দল সদস্যদের সাথে শেয়ার করুন। পরিভাষা নির্ভুলভাবে ব্যবহার করছেন তা নিশ্চিত করতে প্রতিবেদন লেখার সময় এটি ব্যবহার করুন।

## Dev Case Studies (১১৭টি দেশের ২০০টি case)

**২০০টি বাস্তব-জগতের উন্নয়ন case studies**-এর একটি সংকলিত লাইব্রেরি — তাত্ত্বিক উদাহরণ নয়, বরং সারা বিশ্বের প্রকৃত কর্মসূচি, মূল্যায়ন ও হস্তক্ষেপ।

প্রতিটি case study এভাবে ট্যাগ করা:
- **দেশ** (১১৭টি দেশ প্রতিনিধিত্ব করে)
- **থিম** (স্বাস্থ্য, শিক্ষা, জীবিকা, governance, ইত্যাদি)
- **পদ্ধতি** (RCT, mixed methods, process evaluation, ইত্যাদি)

**কীভাবে ব্যবহার করবেন:** কর্মসূচি ডিজাইনে তথ্য জোগাতে আপনার খাত ও প্রেক্ষাপটের সাথে মেলে এমন case studies খুঁজুন। এগুলো শিক্ষণ উপকরণ হিসেবে ব্যবহার করুন — "এখানে দেখুন কীভাবে বাংলাদেশে একই ধরনের একটি কর্মসূচি মূল্যায়ন করা হয়েছিল।" সাক্ষ্য-অবহিত চিন্তাভাবনা প্রদর্শনে প্রস্তাবনায় এগুলো অন্তর্ভুক্ত করুন।

## DevDiscourses (৫০০+ প্রবন্ধ ও বই)

DevDiscourses হলো উন্নয়ন চর্চার জন্য গুরুত্বপূর্ণ **৫০০-এরও বেশি একাডেমিক প্রবন্ধ, বই ও প্রতিবেদনের** একটি সংকলিত পাঠ্যতালিকা। এটি একটি এলোমেলো ডেটাবেস নয় — প্রতিটি এন্ট্রি বেছে নেওয়া হয়েছে কারণ এটি শুধু শিক্ষাবিদদের নয়, প্র্যাকটিশনারদের জন্য সত্যিকারের উপযোগী।

এন্ট্রিগুলো বিষয় অনুযায়ী সাজানো এবং সহজ ব্রাউজিংয়ের জন্য ট্যাগ করা।

**কীভাবে ব্যবহার করবেন:** আপনার দলের জন্য একটি পাঠ্যতালিকা তৈরি করুন। কোনো বিষয়ে নতুন হলে মৌলিক পাঠ্য খুঁজুন। আপনার নিজের প্রতিবেদন ও প্রস্তাবনায় সেগুলো উদ্ধৃত করুন। গভীর অন্বেষণের জন্য কোর্সের পাশাপাশি এগুলো ব্যবহার করুন।

## Dataverse (২৭০টি সম্পদ)

Dataverse হলো উন্নয়ন তথ্যের জন্য আপনার সূচনা বিন্দু। এতে রয়েছে:

- World Bank, DHS, NFHS, NSSO প্রভৃতি উৎস থেকে **২৭০টি datasets, tools ও API**
- প্রোগ্রাম্যাটিক তথ্য অ্যাক্সেসের জন্য **API**
- তথ্য বিশ্লেষণ ও ভিজ্যুয়ালাইজেশনের জন্য **tools**
- AI-সহায়তায় উন্নয়ন গবেষণার জন্য **MCP servers**

সম্পদগুলো দারিদ্র্য, স্বাস্থ্য, শিক্ষা, জেন্ডার, governance, জলবায়ু এবং আরও অনেক কিছু কভার করে — দক্ষিণ এশীয় তথ্য উৎসের উপর জোর দিয়ে যা প্রায়ই খুঁজে পাওয়া কঠিন।

**কীভাবে ব্যবহার করবেন:** আপনার গবেষণা বা মূল্যায়নের জন্য সঠিক dataset খুঁজুন। আপনি জানতেন না এমন তথ্য উৎস আবিষ্কার করুন। আপনার বিশ্লেষণ workflow-তে তথ্য tools সংযুক্ত করুন। আপনি গবেষণার জন্য AI tools ব্যবহার করলে, MCP servers সরাসরি উন্নয়ন তথ্য query করতে সাহায্য করে।

## MCP Server (AI সহকারীদের জন্য)

ImpactMojo-র একটি **Model Context Protocol (MCP) server** আছে যা যেকোনো AI সহকারীকে — Claude Desktop, Claude Code, Cursor বা অন্যান্য MCP-সামঞ্জস্যপূর্ণ clients — আমাদের সম্পূর্ণ জ্ঞানভাণ্ডার প্রোগ্রাম্যাটিকভাবে অনুসন্ধান ও query করতে দেয়।

**১১টি tools উপলব্ধ:**
- `search_content` — সব ৭০০+ কনটেন্ট আইটেম জুড়ে full-text অনুসন্ধান
- `lookup_bct` / `search_bcts` / `list_bct_categories` — দক্ষিণ এশীয় প্রেক্ষাপট ও case studies-সহ ২০৩টি BCT কৌশল
- `browse_dataverse` / `search_dataverse` — ২৭০টি tools, datasets, API
- `list_challenges` / `get_challenge` — rubrics-সহ অনুশীলন
- `list_courses` — ৬টি learning tracks জুড়ে ৫৩টি কোর্স
- `get_game_info` — AI agent personas-সহ ১৬টি অর্থনীতি simulation games
- `query_climate_data` — Climate TRACE থেকে India GHG emissions

**কীভাবে ব্যবহার করবেন:** MCP server স্থানীয়ভাবে ইনস্টল করুন, আপনার AI সহকারীর সাথে সংযুক্ত করুন এবং "find BCT techniques for nutrition in India" বা "what climate data does ImpactMojo have?" এর মতো প্রশ্ন জিজ্ঞাসা করুন। সেটআপ নির্দেশাবলীর জন্য [MCP Server README](https://github.com/ImpactMojo/ImpactMojo/tree/main/mcp-server) দেখুন।
