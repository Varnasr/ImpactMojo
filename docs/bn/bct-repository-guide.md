# BCT Repository গাইড

## BCT Repository কী?

ImpactMojo BCT Repository হল **200+ আচরণ পরিবর্তন কৌশলের (Behaviour Change Techniques) একটি বিনামূল্যের, অনুসন্ধানযোগ্য সংগ্রহ** — যা আন্তর্জাতিকভাবে স্বীকৃত BCT Taxonomy v1 (93টি মূল কৌশল)-কে দক্ষিণ এশীয় উন্নয়ন অনুশীলনের প্রেক্ষাপটে রূপায়িত 100+ অতিরিক্ত কৌশলের সাথে একত্রিত করে।

আপনি যদি স্বাস্থ্য কর্মসূচি, WASH হস্তক্ষেপ, শিক্ষা প্রচারাভিযান, বা মানুষের আচরণ পরিবর্তনের লক্ষ্যে কোনো কাজ ডিজাইন করেন, তাহলে এই repository আপনাকে প্রমাণ-সমর্থিত সঠিক কৌশল খুঁজে পেতে সাহায্য করে — এবং আপনার প্রস্তাব ও logframes-এ সেগুলির প্রমিত IDs ব্যবহার করতে সাহায্য করে।

---

## আচরণ পরিবর্তন কৌশল কী?

একটি **আচরণ পরিবর্তন কৌশল (Behaviour Change Technique, BCT)** হল আচরণ পরিবর্তনের জন্য ডিজাইন করা একটি হস্তক্ষেপের একটি নির্দিষ্ট, পুনরুৎপাদনযোগ্য উপাদান। অস্পষ্টভাবে "আমরা সচেতনতা বাড়াব" বলার পরিবর্তে, একটি BCT আপনাকে একটি সংজ্ঞা, প্রমাণ ভিত্তি এবং taxonomy ID সহ একটি সুনির্দিষ্ট কৌশল দেয়।

**উদাহরণ:** BCT 1.1 "লক্ষ্য নির্ধারণ (আচরণ)" — ব্যক্তি একটি নির্দিষ্ট আচরণগত লক্ষ্য নির্ধারণ করেন (যেমন, "আমি প্রতিটি খাবারের আগে হাত ধোব")। এটি এমন একটি কৌশল যাকে আপনি নাম দিতে, পরিমাপ করতে এবং পুনরুৎপাদন করতে পারেন।

আপনার কর্মসূচি ডিজাইনে প্রমিত BCTs ব্যবহার করা হস্তক্ষেপগুলিকে আরও সুনির্দিষ্ট, মূল্যায়নযোগ্য এবং গবেষণাগুলির মধ্যে তুলনীয় করে তোলে।

## Repository কীভাবে সংগঠিত

### বিভাগ অনুসারে

কৌশলগুলি ডোমেন অনুসারে সংগঠিত যাতে আপনি আপনার খাতের জন্য প্রাসঙ্গিক বিষয় খুঁজে পেতে পারেন:

| বিভাগ | কেন্দ্রবিন্দু |
|----------|-------|
| Health | পুষ্টি, মাতৃস্বাস্থ্য, রোগ প্রতিরোধ, WASH আচরণ |
| Education | শেখার অভ্যাস, স্কুল উপস্থিতি, শিক্ষক অনুশীলন |
| Livelihoods | আর্থিক আচরণ, কৃষি অনুশীলন, বাজার অংশগ্রহণ |
| WASH | হাত ধোয়া, স্যানিটেশন গ্রহণ, জল শোধন |
| Gender | লিঙ্গ-সমতাপূর্ণ আচরণ, GBV প্রতিরোধ, নারীর এজেন্সি |
| Governance | নাগরিক অংশগ্রহণ, স্বচ্ছতা, জবাবদিহিতা আচরণ |

### প্রমাণ স্তর অনুসারে

প্রতিটি কৌশল একটি প্রমাণ রেটিং দিয়ে ট্যাগ করা হয়েছে:

- **Strong** — একাধিক কঠোর গবেষণা (RCTs, পদ্ধতিগত পর্যালোচনা) দ্বারা সমর্থিত
- **Moderate** — পর্যবেক্ষণমূলক গবেষণা বা সীমিত পরীক্ষামূলক প্রমাণ দ্বারা সমর্থিত
- **Emerging** — আশাব্যঞ্জক কিন্তু সীমিত আনুষ্ঠানিক মূল্যায়ন সহ

হস্তক্ষেপ ডিজাইন করার সময়, Strong প্রমাণযুক্ত কৌশলগুলিকে অগ্রাধিকার দিন। যেখানে কোনো Strong বিকল্প নেই সেখানে Emerging কৌশল ব্যবহার করুন এবং সেগুলির মূল্যায়নের পরিকল্পনা করুন।

## মূল বৈশিষ্ট্য

### অনুসন্ধান ও ফিল্টারিং

repository-তে fuzzy matching সহ পূর্ণ-পাঠ্য অনুসন্ধান রয়েছে — একটি কীওয়ার্ড, কৌশলের নাম, খাত, বা কর্মসূচির ধরন টাইপ করুন এবং র‍্যাঙ্ক করা ফলাফল পান। আপনি এগুলি দিয়েও ফিল্টার করতে পারেন:

- **বিভাগ** — Health, Education, WASH, Gender, Livelihoods, Governance
- **প্রমাণ স্তর** — Strong, Moderate, Emerging
- **কীওয়ার্ড** — কৌশলের নাম বা সংজ্ঞায় থাকা যেকোনো শব্দ

### কৌশল কার্ড

প্রতিটি কৌশল একটি কার্ড হিসেবে প্রদর্শিত হয় যা দেখায়:

- **Taxonomy ID** (যেমন, BCT 1.1) — প্রমিত শনাক্তকারী
- **নাম** — কৌশলটিকে কী বলা হয়
- **সংজ্ঞা** — কৌশলটিতে আসলে কী জড়িত
- **প্রমাণ স্তর** — রঙ-কোডেড badge
- **বিভাগ ট্যাগ** — এটি কোন কোন খাতে প্রযোজ্য

সম্পর্কিত কৌশল এবং cross-links সহ একটি বিস্তৃত দৃশ্যের জন্য যেকোনো কার্ডে ক্লিক করুন।

### বুকমার্ক ও রপ্তানি

- পরে রেফারেন্সের জন্য একটি ব্যক্তিগত সংগ্রহে **কৌশল সংরক্ষণ করুন**
- কর্মশালার handouts-এর জন্য **পৃথক কার্ড প্রিন্ট করুন**
- বিকল্পগুলির মধ্যে বেছে নিতে **কৌশলগুলি** পাশাপাশি **তুলনা করুন**
- কর্মসূচি নথিতে অন্তর্ভুক্তির জন্য **CSV-তে রপ্তানি করুন**

## শিক্ষকরা BCT Repository কীভাবে ব্যবহার করতে পারেন

### কোর্স ডিজাইনে

হস্তক্ষেপ ডিজাইন শেখানোর সময় repository-কে একটি রেফারেন্স হিসেবে ব্যবহার করুন। শিক্ষার্থীদের দিয়ে করান:

1. তারা যে আচরণ পরিবর্তন করতে চান তা শনাক্ত করুন
2. প্রাসঙ্গিক কৌশলের জন্য repository অনুসন্ধান করুন
3. Strong বনাম Emerging প্রমাণ বিকল্প তুলনা করুন
4. পরিপূরক কৌশলের একটি সংমিশ্রণ নির্বাচন করুন
5. প্রমিত BCT IDs ব্যবহার করে তাদের হস্তক্ষেপ লিখুন

### কর্মশালায়

- **প্রাক-পঠন:** সেশনের আগে অংশগ্রহণকারীদের একটি নির্দিষ্ট বিভাগ ব্রাউজ করতে নিয়োগ করুন
- **কার্যকলাপ:** দলগুলিকে একটি কেস স্টাডি দিন এবং তাদের হস্তক্ষেপ ডিজাইনের জন্য 3–5টি BCTs নির্বাচন করতে বলুন
- **আলোচনা:** দলের নির্বাচনগুলি তুলনা করুন — কেন বিভিন্ন গোষ্ঠী বিভিন্ন কৌশল বেছে নিল?

### প্রস্তাব লেখায়

অংশগ্রহণকারীদের প্রস্তাবে BCT taxonomy IDs রেফারেন্স করতে শেখান। তহবিলদাতারা ক্রমবর্ধমানভাবে প্রমাণ-ভিত্তিক হস্তক্ষেপ ডিজাইন প্রত্যাশা করেন, এবং নির্দিষ্ট BCTs উদ্ধৃত করা (যেমন, "আমরা BCT 1.1 লক্ষ্য নির্ধারণ এবং BCT 2.2 আচরণের উপর ফিডব্যাক ব্যবহার করব") কঠোরতার ইঙ্গিত দেয়।

### Theory of Change-এর সাথে সংযোগ

BCTs সরাসরি Theory of Change-এর "কার্যকলাপ" এবং "ব্যবস্থা" স্তরের সাথে মেলে। নির্দিষ্ট কৌশলগুলি কীভাবে নির্দিষ্ট ফলাফল চালিত করে তা দেখাতে repository-কে Theory of Change Lab-এর সাথে ব্যবহার করুন।

3. **প্রমাণ স্তর অনুসারে ফিল্টার করুন** — Strong প্রমাণ কৌশল দিয়ে শুরু করুন
4. **কীওয়ার্ড দিয়ে অনুসন্ধান করুন** — "self-monitoring," "social support," বা "incentive"-এর মতো শব্দ চেষ্টা করুন
5. **দরকারি কৌশল বুকমার্ক করুন** — আপনার কর্মসূচি ক্ষেত্রের জন্য একটি সংগ্রহ তৈরি করুন

## টিপস

- **পরিপূরক কৌশল একত্রিত করুন।** কার্যকর আচরণ পরিবর্তন হস্তক্ষেপ সাধারণত একসাথে 3–7টি BCTs ব্যবহার করে, শুধু একটি নয়।
- **আপনার প্রেক্ষাপটে প্রমাণ যাচাই করুন।** বিশ্বব্যাপী Strong প্রমাণযুক্ত একটি কৌশলের দক্ষিণ এশীয় পরিবেশে সীমিত প্রমাণ থাকতে পারে — যেখানে প্রাসঙ্গিক সেখানে repository এটি চিহ্নিত করে।
- **taxonomy IDs সামঞ্জস্যপূর্ণভাবে ব্যবহার করুন।** প্রস্তাব, M&E পরিকল্পনা, বা গবেষণাপত্র লেখার সময়, স্পষ্টতা ও তুলনীয়তার জন্য সর্বদা নামের সাথে BCT ID অন্তর্ভুক্ত করুন।
- **পরিচিত দিয়ে শুরু করুন।** আপনি যদি ইতিমধ্যে "সচেতনতা প্রচারাভিযান" করেন, তাহলে অনুসন্ধান করুন সেই প্রচারাভিযানগুলি আসলে কোন BCTs ব্যবহার করে — আপনি দেখতে পারেন যে আপনি ইতিমধ্যে BCT 5.1 "স্বাস্থ্য পরিণতি সম্পর্কে তথ্য"-এর মতো কৌশল নাম না দিয়ে প্রয়োগ করছেন।
