## শিক্ষণ ট্র্যাক

কনটেন্ট 6টি ট্র্যাকে সংগঠিত:

1. **MEL & Research** — পর্যবেক্ষণ, মূল্যায়ন, গুণগত/পরিমাণগত পদ্ধতি
2. **Economics & Policy** — উন্নয়ন অর্থনীতি, রাজনৈতিক অর্থনীতি, fundraising
3. **Gender & Equity** — জেন্ডার স্টাডিজ, WEE, care economy, data feminism
4. **Governance & Society** — সংবিধান, ঔপনিবেশিকতা-মুক্তি, কমিউনিটি উন্নয়ন
5. **Health & Wellbeing** — জনস্বাস্থ্য, জলবায়ু, SEL, জীবিকা
6. **Communication & Data** — ডেটা সাক্ষরতা, visual ethnography, BCC, advocacy

## Flagship কোর্স কাঠামো

প্রতিটি flagship কোর্স একটি সামঞ্জস্যপূর্ণ কাঠামো অনুসরণ করে:

- **13টি মডিউল** (প্রায়)
- 50–65টি মূল পরিভাষার **Lexicon**
- **দক্ষিণ এশীয় প্রেক্ষাপট** — ভারত, বাংলাদেশ, নেপাল, শ্রীলঙ্কা থেকে উদাহরণ
- **কেস স্টাডি** — প্রকৃত উন্নয়ন প্রোগ্রাম এবং মূল্যায়ন
- **প্রতিফলনের অনুরোধ** — অনুশীলনকারীদের তাদের কাজের সাথে সংযুক্ত করতে
- **আরও পঠন** — DevDiscourses থেকে নির্বাচিত

Module 1:  What is MEL?

## Interactive Labs

ল্যাব হল HTML/JS workbench যা অনুশীলনকারীদের ধারণা প্রয়োগ করতে দেয়। প্রতিটি ল্যাব:

- একটি নির্দেশিত workflow আছে (ধাপে ধাপে)
- একটি আউটপুট তৈরি করে (framework, পরিকল্পনা, বিশ্লেষণ)
- ফলাফল export করতে পারে (premium সংস্করণে PDF/PNG)
- কোনো সার্ভারের প্রয়োজন নেই — সম্পূর্ণরূপে ব্রাউজারে চলে

## Learning Games

গেম হল একক HTML পৃষ্ঠা হিসেবে তৈরি অর্থনীতির সিমুলেশন:

- **স্বয়ংসম্পূর্ণ** — প্রতিটি গেম একটি HTML ফাইল
- **ডেটা-চালিত** — যেখানে সম্ভব প্রকৃত অর্থনৈতিক প্যারামিটার
- **debrief করার যোগ্য** — শ্রেণিকক্ষ বা কর্মশালা ব্যবহারের জন্য ডিজাইন করা
- **মোবাইল-বান্ধব** — responsive layout

## নতুন কনটেন্ট যোগ করা

### একটি নতুন foundational কোর্স যোগ করা

1. বিদ্যমান কোর্স প্যাটার্ন অনুসরণ করে একটি নতুন HTML ফাইল তৈরি করুন
2. কোর্সটি `catalog.html`-এর ক্যাটালগে যোগ করুন
3. এটি মূল সাইটের কোর্স তালিকায় `index.html`-এ যোগ করুন
4. README কনটেন্ট ইনভেন্টরি আপডেট করুন

### একটি নতুন গেম যোগ করা

1. গেম logic সহ একটি একক HTML ফাইল তৈরি করুন
2. এটি উপযুক্ত ডিরেক্টরিতে বা একটি পৃথক Netlify সাইট হিসেবে হোস্ট করুন
3. এটি `index.html` এবং `catalog.html`-এর গেম বিভাগে যোগ করুন

### Handouts যোগ করা

Handouts রিপোজিটরি থেকে গতিশীলভাবে লোড হয়। Handouts সংগ্রহে HTML ফাইল যোগ করুন এবং সেগুলো স্বয়ংক্রিয়ভাবে প্রদর্শিত হবে।

## বহুভাষিক কনটেন্ট

কনটেন্ট 6টি ভাষায় উপলব্ধ:
- ইংরেজি (প্রাথমিক)
- হিন্দি
- তামিল
- বাংলা
- তেলেগু
- মারাঠি

অনুবাদের অবদান স্বাগত। নির্দেশিকার জন্য [Contributing](Contributing) দেখুন।

## স্টাইল গাইড

- **টোন:** সহজলভ্য কিন্তু কঠোর। 2–3 বছরের অভিজ্ঞতাসম্পন্ন একজন অনুশীলনকারীর জন্য লিখুন।
- **উদাহরণ:** দক্ষিণ এশীয় প্রেক্ষাপটকে অগ্রাধিকার দিন (ভারত, বাংলাদেশ, নেপাল, শ্রীলঙ্কা)।
- **পরিভাষা:** প্রথম ব্যবহারে পরিভাষা সংজ্ঞায়িত করুন। সেক্টর-মানক হলে সেগুলো ImpactLex-এ যোগ করুন।
- **স্বীকৃতি:** উৎস উল্লেখ করুন। যেখানে সম্ভব DevDiscourses-এর সাথে লিঙ্ক করুন।
- **অ্যাক্সেসিবিলিটি:** semantic HTML, ছবির জন্য alt text, এবং পর্যাপ্ত রঙের কনট্রাস্ট ব্যবহার করুন।

## কীভাবে একটি Deep Dive লিখবেন

Deep Dives হল নির্বাচিত টীকাযুক্ত পঠন তালিকা। প্রতিটি তালিকা একটি সম্পাদকীয় শিল্পকর্ম যেখানে একজন নামধারী কিউরেটরের কণ্ঠ থাকে, একটি নিরপেক্ষ গ্রন্থপঞ্জি নয় — একটি স্বতন্ত্র রেফারেন্স পৃষ্ঠার চেয়ে একটি দীর্ঘ-রূপের প্রবন্ধ-হিসেবে-পাঠ্যক্রমের কাছাকাছি।

### একটি Deep Dive-এর শারীরবৃত্ত

1. **Hero** — শিরোনাম, এক-লাইন ট্যাগলাইন, বিষয় chip, পঠনের সংখ্যা।
2. **Curator card** — নাম, ভূমিকা, 2–3 বাক্যের বায়ো। `Editor's Pick` (ইন-হাউস) বা `Invited Curator` হিসেবে চিহ্নিত করুন।
3. **Editor's Note** — কিউরেটরের কণ্ঠে 2–4 অনুচ্ছেদের framing প্রবন্ধ। এটিই সারবস্তু; তালিকা হল রসিদ।
4. **3–6টি থিমযুক্ত বিভাগ** — যেমন "Foundations", "Recent Debates", "Voices from the Field"। একটি সমতল তালিকা তৈরি করবেন না।
5. **পঠন আইটেম** — প্রতিটির জন্য: একটি ধরন badge (📘 Book / 📄 Paper / 🎙 Podcast / 🎬 Film / 📊 Dataset / 📰 Article / 🌐 Web), একটি outbound লিঙ্কসহ একটি সম্পূর্ণ উদ্ধৃতি, এবং কাজটি কেন গুরুত্বপূর্ণ এবং এটি পাঠ্যক্রমে কীভাবে মানানসই তা বলে এমন 2–4 বাক্যের টীকা।
6. **সম্পর্কিত ImpactMojo কনটেন্ট** — 2–4টি কোর্স, ল্যাব, গেম বা বই সঙ্গী cross-link করুন।
7. **প্রস্তাবিত উদ্ধৃতি** — APA-শৈলীর উদ্ধৃতি ব্লক।
8. **Contribute CTA** — pitch ফর্মের লিঙ্ক।

### তৈরি / আপডেট করার ফাইল

একটি নতুন Deep Dive যোগ করতে:

1. `/DeepDives/_template.html` → `/DeepDives/{slug}.html` কপি করুন। শিরোনাম, ট্যাগলাইন, বিষয়, কিউরেটর, editor's note, বিভাগ, পঠন পূরণ করুন।
2. `/data/deep-dives.json`-এ একটি এন্ট্রি যোগ করুন (id, title, tagline, topic, url, curator, sections, tags, reading_count, published)।
3. `/data/search-index.json`-এ `"type": "deep-dive"` এবং `"category": "Deep Dives"` সহ একটি এন্ট্রি যোগ করুন।
4. `/sitemap.xml`-এ একটি `<url>` এন্ট্রি যোগ করুন।
5. `catalog.html`-এর `allContent` array-তে একটি card যোগ করুন (`type: 'deep-dive'`, একটি ট্র্যাক বেছে নিন)।
6. (ঐচ্ছিক) flagship-মানের হলে `/index.html`-এ Deep Dives বিভাগ সম্পাদনা করে হোমপেজে ফিচার করুন।
7. সর্বত্র সংখ্যা টেক্সট আপডেট করুন — `(5 Deep Dives|5 readings)` grep করুন এবং সংখ্যা বাড়ান।

### সম্পাদকীয় নির্দেশিকা

- **নিরপেক্ষতার উপর কিউরেটরের কণ্ঠ।** দৃষ্টিভঙ্গিহীন একটি তালিকা কেবল একটি গ্রন্থপঞ্জি। পাঠকের হাতে আপনি কী তুলে দিতে চান এবং কেন তা বলুন।
- **মিশ্র মিডিয়া উৎসাহিত।** একটি ভালো Deep Dive-এ একাডেমিক মূলের পাশাপাশি অন্তত একটি পডকাস্ট, একটি dataset এবং একটি অনুশীলনকারী-মুখী উৎস থাকে।
- **টীকা দিন, সারাংশ নয়।** দুই থেকে চারটি বাক্য। কেন এই কাজ, কেন এখন, কার পড়া উচিত।
- **উদারভাবে cross-link করুন।** তালিকার উপর ভিত্তি করে গড়া কোর্স, ল্যাব এবং বই সঙ্গীতে পাঠকদের পাঠাতে "Related ImpactMojo Content" ব্লক ব্যবহার করুন।
- **পরিধির মধ্যে থাকুন।** প্রতিটি Deep Dive একটি সুসংগত বিষয় — সম্পূর্ণ একটি ক্ষেত্র কভার করার চেষ্টা করবেন না।
