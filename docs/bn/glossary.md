# Glossary

ImpactMojo ব্যবহার করার সময় বা উন্নয়ন ক্ষেত্রে ডিজিটাল সরঞ্জাম নিয়ে কাজ করার সময় আপনি যে প্রযুক্তিগত শব্দগুলোর মুখোমুখি হতে পারেন, তার একটি সহজ-ভাষার নির্দেশিকা। প্রতিটি সংজ্ঞা সেইসব বুদ্ধিমান, অভিজ্ঞ পেশাদারদের জন্য লেখা হয়েছে যারা ঘটনাচক্রে প্রযুক্তি ক্ষেত্রে কাজ করেন না।

---

## A

### Accessibility (a11y)

ওয়েবসাইট, নথি, এবং সরঞ্জামগুলো এমনভাবে ডিজাইন করার অনুশীলন যাতে সেগুলো সবাই ব্যবহার করতে পারে — যার মধ্যে দৃষ্টিপ্রতিবন্ধী, শ্রবণশক্তি হারানো, চলাফেরায় অক্ষমতা, বা জ্ঞানীয় ভিন্নতাযুক্ত ব্যক্তিরাও আছেন। "a11y" সংক্ষেপটি একটি শর্টহ্যান্ড: "a", তারপর ১১টি অক্ষর, তারপর "y"।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনি যদি প্রশিক্ষণ সামগ্রী, প্রতিবেদন, বা ডিজিটাল কন্টেন্ট তৈরি করেন, তবে অ্যাক্সেসিবিলিটি নিশ্চিত করে যে আপনার দলের বা আপনার সম্প্রদায়ের কেউ বাদ পড়বে না। এটি কন্টেন্টকে *সবার* জন্যই আরও ভালো করে তোলে — স্পষ্ট কাঠামো, ভালো বৈসাদৃশ্য, আরও পঠনযোগ্য টেক্সট। ImpactMojo অ্যাক্সেসিবিলিটি মাথায় রেখে তৈরি করা হয়েছে, যা WCAG নির্দেশিকা অনুসরণ করে (নিচে দেখুন)।

---

### API (Application Programming Interface)

এক সফটওয়্যারের অন্য সফটওয়্যার থেকে তথ্য চাওয়ার একটি কাঠামোবদ্ধ উপায়। আপনি যখন কোনো ওয়েবসাইটে যান, তখন আপনার ব্রাউজার মূলত কন্টেন্ট আনতে সাইটের API ব্যবহার করছে। কিন্তু শব্দটি সাধারণত *ডেটা API* বোঝায় — এমন পরিষেবা যা আপনাকে নির্দিষ্ট ডেটা চাইতে দেয় (যেমন, "২০১৫ থেকে ২০২৩ পর্যন্ত ভারতের শিশুমৃত্যুর হার") এবং ঠিক সেটিই ফিরিয়ে দেয়, এমন একটি বিন্যাসে যা একটি কম্পিউটার কাজে লাগাতে পারে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনার যদি নিয়মিত World Bank, WHO, বা ভারতীয় আদমশুমারির মতো সংস্থাগুলো থেকে ডেটা প্রয়োজন হয়, তবে API আপনাকে ম্যানুয়ালি ওয়েবসাইট ঘুরে ও ফাইল ডাউনলোড না করেই ঠিক যা দরকার তা টেনে আনতে দেয়। অনেক API বিনামূল্যে এবং সরল ওয়েব-ভিত্তিক ইন্টারফেস আছে — এগুলো ব্যবহার করতে আপনাকে কোড লিখতে হবে না, যদিও কোড সেগুলোকে আরও শক্তিশালী করে। কোন কোন সম্পদ API অফার করে তা ImpactMojo [Dataverse](dataverse-guide.md) চিহ্নিত করে।

## C

### CC BY-NC-ND 4.0

একটি Creative Commons লাইসেন্স — নির্দিষ্টভাবে, **Attribution-NonCommercial-NoDerivatives 4.0 International**। এই লাইসেন্সই ImpactMojo-র শিক্ষামূলক কন্টেন্ট (কোর্স, হ্যান্ডআউট, গেম, ল্যাব) কভার করে।

প্রতিটি অংশের অর্থ এখানে দেওয়া হলো:

- **BY** — কন্টেন্ট শেয়ার করার সময় আপনাকে ImpactMojo-কে কৃতিত্ব দিতে হবে
- **NC (NonCommercial)** — আপনি কন্টেন্ট বিক্রি করতে বা বাণিজ্যিক উদ্দেশ্যে ব্যবহার করতে পারবেন না
- **ND (NoDerivatives)** — আপনি কন্টেন্ট পরিবর্তন করে পরিবর্তিত সংস্করণ বিতরণ করতে পারবেন না

**আপনি *যা* করতে পারেন:** আপনার দলের সাথে হ্যান্ডআউট শেয়ার করা, আপনার প্রশিক্ষণ সেশনে কোর্স ব্যবহার করা, আপনার ওয়েবসাইট থেকে কন্টেন্টে লিংক দেওয়া, কর্মশালার জন্য সামগ্রী প্রিন্ট করা — সবই বিনামূল্যে, যতক্ষণ আপনি ImpactMojo-কে কৃতিত্ব দেন এবং এর জন্য চার্জ না করেন বা পরিবর্তন না করেন।

**আপনি *যা* করতে পারবেন না:** মুদ্রিত কপি বিক্রি করা, কন্টেন্টকে নিজের ব্র্যান্ড হিসেবে পুনঃব্র্যান্ড করা, বা বিতরণের জন্য পরিবর্তিত সংস্করণ তৈরি করা।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** এই লাইসেন্স ImpactMojo কন্টেন্টকে বিনামূল্যে ও সামঞ্জস্যপূর্ণ রাখে, একই সাথে আপনাকে আপনার কর্মসূচি ও শিক্ষাদানে এটি ব্যাপকভাবে ব্যবহার করতে দেয়।

### CDN (Content Delivery Network)

বিশ্বজুড়ে বহু স্থানে ছড়িয়ে থাকা সার্ভারের একটি নেটওয়ার্ক। আপনি যখন CDN ব্যবহারকারী কোনো ওয়েবসাইটে যান, তখন কন্টেন্ট আপনার ভৌগোলিকভাবে সবচেয়ে কাছের সার্ভার থেকে পরিবেশিত হয়, দূরে থাকতে পারে এমন একটি কেন্দ্রীয় অবস্থান থেকে নয়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** এই কারণেই দক্ষিণ এশিয়ার গ্রামীণ এলাকায় ধীর সংযোগেও ImpactMojo পৃষ্ঠাগুলো মোটামুটি দ্রুত লোড হয়। প্রতিটি অনুরোধ অন্য দেশের সার্ভারে যাওয়ার পরিবর্তে, CDN কাছাকাছি অবস্থান থেকে কন্টেন্ট সরবরাহ করে। এর সুবিধা পেতে আপনাকে কিছু করতে হবে না — এটি স্বয়ংক্রিয়ভাবে কাজ করে।

### CSV (Comma-Separated Values)

সারণিবদ্ধ ডেটার জন্য একটি সরল ফাইল বিন্যাস — স্প্রেডশিটের মতো, তবে সাধারণ টেক্সট হিসেবে সংরক্ষিত। প্রতিটি সারি একটি লাইন, এবং প্রতিটি কলাম একটি কমা দিয়ে আলাদা করা হয়। একটি CSV ফাইল Excel, Google Sheets, বা যেকোনো ডেটা সরঞ্জামে খোলা যায়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ডেটা শেয়ার করার জন্য CSV সবচেয়ে সর্বজনীন বিন্যাস। কেউ যদি আপনাকে একটি ডেটাসেট পাঠায়, তবে সেটি CSV হওয়ার ভালো সম্ভাবনা আছে। আপনার যদি সিস্টেমের মধ্যে ডেটা সরাতে হয় (যেমন, একটি জরিপ সরঞ্জাম থেকে একটি পরিসংখ্যান প্রোগ্রামে), তবে CSV সাধারণত সেই সাধারণ ভাষা যা উভয়েই বোঝে। ImpactMojo Dataverse-এর বেশিরভাগ সম্পদ CSV বিন্যাসে ডেটা সরবরাহ করে।

## E

### Edge Function

কোডের একটি ছোট অংশ যা অনুরোধকারী ব্যক্তির ভৌগোলিকভাবে কাছাকাছি অবস্থিত একটি সার্ভারে চলে, হাজার হাজার কিলোমিটার দূরে থাকতে পারে এমন একটি কেন্দ্রীয় সার্ভারে নয়। "Edge" বলতে নেটওয়ার্কের প্রান্ত বোঝায় — ব্যবহারকারীর সবচেয়ে কাছের বিন্দু।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo কিছু বৈশিষ্ট্যের জন্য (যেমন লগইন এবং সার্টিফিকেট তৈরি) edge functions ব্যবহার করে যাতে আপনি যেখানেই থাকুন না কেন সেগুলো দ্রুত সাড়া দেয়। আপনি যদি পাটনা বা চট্টগ্রামে থাকেন, তবে দূরবর্তী ডেটা সেন্টারে যাত্রার জন্য অপেক্ষা না করে ফাংশনটি কাছাকাছি একটি সার্ভারে চলে। এটি ঘটতে আপনি দেখবেন না — কেবল জিনিসগুলো দ্রুত মনে হবে।

## G

### Git / GitHub

**Git** একটি সংস্করণ নিয়ন্ত্রণ সিস্টেম — এমন সফটওয়্যার যা সময়ের সাথে ফাইলের একটি সেটে করা প্রতিটি পরিবর্তন ট্র্যাক করে। এটিকে Microsoft Word-এ "Track Changes"-এর মতো ভাবুন, তবে শত শত ফাইলযুক্ত সম্পূর্ণ প্রকল্পের জন্য। প্রতিটি পরিবর্তন রেকর্ড করা হয়: কে করেছে, কখন, এবং ঠিক কী পরিবর্তন করা হয়েছে। আপনি যেকোনো সময় যেকোনো পূর্ববর্তী সংস্করণে ফিরে যেতে পারেন।

**GitHub** একটি ওয়েবসাইট যেখানে মানুষ Git দিয়ে পরিচালিত প্রকল্প সংরক্ষণ ও শেয়ার করে। এখানেই ImpactMojo-র কোড থাকে, এবং এখানেই অবদানকারীরা পরিবর্তনের পরামর্শ দিতে বা সমস্যা রিপোর্ট করতে পারেন।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনি যদি ImpactMojo-তে অবদান রাখতে চান (অনুবাদ, কন্টেন্ট, কোড), তবে আপনি GitHub-এর সাথে যোগাযোগ করবেন। এমনকি আপনি অবদান না রাখলেও, ImpactMojo যে GitHub-এ আছে তা বোঝা মানে আপনি ঠিক দেখতে পারেন এই প্ল্যাটফর্মটি কীভাবে তৈরি — এটি সবই সর্বজনীন।

## H

### HTML / CSS / JavaScript

আপনি যে প্রতিটি ওয়েব পৃষ্ঠা পরিদর্শন করেন তা তৈরি করে এমন তিনটি মূল প্রযুক্তি:

- **HTML** (HyperText Markup Language) — কাঠামো ও কন্টেন্ট। এটি সংজ্ঞায়িত করে পৃষ্ঠায় কী আছে: শিরোনাম, অনুচ্ছেদ, ছবি, লিংক।
- **CSS** (Cascading Style Sheets) — চেহারা। এটি সংজ্ঞায়িত করে জিনিসগুলো কেমন দেখায়: রঙ, ফন্ট, ব্যবধান, লেআউট।
- **JavaScript** — আচরণ। এটি পৃষ্ঠাগুলোকে ইন্টারঅ্যাক্টিভ করে: কুইজ যা আপনার উত্তর পরীক্ষা করে, চার্ট যা আপডেট হয়, মেনু যা খোলে ও বন্ধ হয়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo ফ্রন্টএন্ডে এই তিনটি প্রযুক্তি দিয়ে তৈরি এবং আর কিছু নয় — কোনো জটিল frameworks বা build সরঞ্জাম নেই। এর মানে এটি দ্রুত লোড হয়, যেকোনো ডিভাইসে কাজ করে, এবং অফলাইনে পরিবেশন করা যায়। আপনি যদি কখনো বুঝতে চান কোনো বৈশিষ্ট্য কীভাবে কাজ করে, তবে পৃষ্ঠার সোর্স দেখলে আপনি পঠনযোগ্য HTML, CSS, এবং JavaScript দেখতে পাবেন।

### HTTPS / SSH

ইন্টারনেটে নিরাপদ যোগাযোগের জন্য দুটি প্রোটোকল (পদ্ধতি):

- **HTTPS** (HyperText Transfer Protocol Secure) — HTTP-এর নিরাপদ সংস্করণ, যে প্রোটোকল আপনার ব্রাউজার ওয়েব পৃষ্ঠা লোড করতে ব্যবহার করে। আপনি যখন আপনার ব্রাউজারের অ্যাড্রেস বারে তালা আইকন দেখেন, তখন আপনি HTTPS ব্যবহার করছেন। এর মানে আপনার ডিভাইস ও ওয়েবসাইটের মধ্যে যাতায়াত করা ডেটা এনক্রিপ্ট করা — মাঝে কেউ এটি পড়তে পারবে না।
- **SSH** (Secure Shell) — দূরবর্তী কম্পিউটারের সাথে নিরাপদে সংযোগ ও পরিচালনার একটি প্রোটোকল। ডেভেলপাররা সার্ভার অ্যাক্সেস করতে এবং GitHub-এ কোড পুশ করতে এটি ব্যবহার করেন।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo সমস্ত সংযোগের জন্য HTTPS ব্যবহার করে, যার মানে আপনার লগইন শংসাপত্র, অগ্রগতি ডেটা, এবং ব্যক্তিগত তথ্য পরিবহনের সময় এনক্রিপ্ট করা থাকে। ক্যাফে, বিমানবন্দর, বা শেয়ার করা অফিস স্থানে পাবলিক Wi-Fi নেটওয়ার্কে এটি বিশেষভাবে গুরুত্বপূর্ণ।

## J

### JWT (JSON Web Token)

একটি সংক্ষিপ্ত, নিরাপদ টোকেন (এনকোড করা ডেটার একটি ছোট অংশ) যা একটি ওয়েবসাইট আপনার লগইন করার পরে আপনার ব্রাউজারে পাঠায়। প্রতিবার আপনি একটি নতুন পৃষ্ঠায় যান বা ডেটার অনুরোধ করেন, আপনার ব্রাউজার এই টোকেনটি ফেরত পাঠায় প্রমাণ করতে যে আপনিই সেই ব্যক্তি যিনি লগইন করেছিলেন — আপনার পাসওয়ার্ড আবার পাঠানোর প্রয়োজন ছাড়াই।

**এভাবে ভাবুন:** আপনি যখন একটি হোটেলে চেক ইন করেন, তখন আপনি একটি রুম কি কার্ড পান। আপনি প্রতিবার আপনার রুমে যাওয়ার সময় আপনার পরিচয়পত্র দেখান না — শুধু কার্ডটি ট্যাপ করেন। JWT ওয়েবসাইটের জন্য ঠিক একইভাবে কাজ করে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনি যখন একটি ImpactMojo অ্যাকাউন্ট তৈরি করে লগইন করেন, তখন পৃষ্ঠাগুলোর মধ্যে চলাচল করার সময় আপনাকে লগইন করা রাখে JWT। এটিই নিশ্চিত করে যে আপনার অগ্রগতি, বুকমার্ক, এবং সার্টিফিকেট অন্য কারও নয়, *আপনার*। টোকেনটি একটি নির্দিষ্ট সময়ের পরে মেয়াদ শেষ হয়ে যায়, তাই কেউ এটি ধরে ফেললেও, এটি বেশিক্ষণ কাজ করবে না।

## M

### MCP Server (Model Context Protocol)

AI সহকারীদের (যেমন Claude) বাহ্যিক ডেটা উৎস ও পরিষেবার সাথে সংযুক্ত করার একটি মানসম্মত উপায়। একটি MCP Server একটি সেতু হিসেবে কাজ করে: AI সহকারী MCP সংযোগের মাধ্যমে একটি অনুরোধ পাঠায়, এবং সার্ভার সংযুক্ত উৎস থেকে প্রকৃত, বর্তমান ডেটা পুনরুদ্ধার করে।

**এভাবে ভাবুন:** কল্পনা করুন আপনার গবেষণা সহকারীর কাছে একটি নির্দিষ্ট ডেটাবেসের লাইব্রেরি কার্ড আছে। তারা আপনার জন্য তথ্য খুঁজে বের করতে পারে, আপনাকে নিজে লাইব্রেরিতে যাওয়ার প্রয়োজন ছাড়াই। একটি MCP Server হলো সেই লাইব্রেরি কার্ড — এটি একটি AI সহকারীকে একটি নির্দিষ্ট ডেটা উৎসে অনুমোদিত অ্যাক্সেস দেয়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** উন্নয়ন গবেষণায় AI সরঞ্জাম যত সাধারণ হয়ে উঠছে, MCP Server আপনাকে স্বাভাবিক কথোপকথনের মাধ্যমে নির্ভরযোগ্য, অফিসিয়াল ডেটা অ্যাক্সেস করতে দেয়। একটি জটিল সরকারি ডেটা পোর্টালে নেভিগেট করার পরিবর্তে, আপনি আপনার AI সহকারীকে একটি প্রশ্ন জিজ্ঞাসা করে প্রকৃত ডেটা ফিরে পেতে পারেন। উন্নয়ন ডেটার জন্য উপলব্ধ MCP Server-গুলো ImpactMojo [Dataverse](dataverse-guide.md) তালিকাভুক্ত করে।

## N

### Netlify

একটি ওয়েব হোস্টিং প্ল্যাটফর্ম — যে পরিষেবা ImpactMojo-র ওয়েবসাইট আপনার ব্রাউজারে পরিবেশন করে। আপনি যখন impactmojo.in-এ যান, তখন Netlify হলো সেই অবকাঠামো যা পৃষ্ঠাগুলো সরবরাহ করে।

**এভাবে ভাবুন:** ImpactMojo যদি একটি লাইব্রেরি হয়, তবে Netlify হলো সেই ভবন যেখানে লাইব্রেরিটি অবস্থিত। এটি পৃষ্ঠার ভৌত সরবরাহ পরিচালনা করে, সাইটটিকে চব্বিশ ঘণ্টা উপলব্ধ রাখে, এবং তার CDN-এর মাধ্যমে HTTPS নিরাপত্তা ও দ্রুত লোডিংয়ের মতো বিষয়গুলো পরিচালনা করে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনাকে প্রায় কখনোই সরাসরি Netlify নিয়ে ভাবতে হবে না। কিন্তু আপনি যদি লক্ষ্য করেন সাইটটি দ্রুত লোড হচ্ছে, উপলব্ধ থাকছে, এবং মোবাইলে ভালো কাজ করছে — তবে আংশিকভাবে সেটি Netlify-র অবকাঠামোর কাজ। ImpactMojo-র অবদানকারীরাও উপকৃত হন কারণ Netlify ডিপ্লয়মেন্ট সহজ করে: কোডের পরিবর্তন স্বয়ংক্রিয়ভাবে লাইভ সাইটে প্রতিফলিত হয়।

## O

### Open Badges

**যাচাইযোগ্য ডিজিটাল সার্টিফিকেট ও শংসাপত্রের** জন্য একটি W3C (World Wide Web Consortium) স্ট্যান্ডার্ড। একটি Open Badge হলো একটি ডিজিটাল ছবি যাতে এম্বেড করা মেটাডেটা থাকে — কে এটি অর্জন করেছে, কে এটি ইস্যু করেছে, কোন মানদণ্ড পূরণ হয়েছে, এবং কখন। এই মেটাডেটা যে কেউ স্বাধীনভাবে যাচাই করতে পারে।

**এভাবে ভাবুন:** একটি কাগজের সার্টিফিকেট ফটোকপি বা জাল করা যায়। একটি Open Badge হলো একটি অন্তর্নির্মিত যাচাইকরণ ব্যবস্থা সহ একটি সার্টিফিকেটের মতো — যে কেউ এতে ক্লিক করে নিশ্চিত করতে পারে যে এটি আসল।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনি যখন একটি ImpactMojo কোর্স সম্পূর্ণ করে একটি সার্টিফিকেট অর্জন করেন, তখন এটি একটি Open Badge হিসেবে ইস্যু করা হয়। আপনি এটি LinkedIn-এ শেয়ার করতে পারেন, একটি CV-তে অন্তর্ভুক্ত করতে পারেন, বা আপনার প্রতিষ্ঠানকে দেখাতে পারেন — এবং যে কেউ এতে ক্লিক করে যাচাই করতে পারে যে আপনি প্রকৃতপক্ষে কোর্সটি সম্পূর্ণ করেছেন। এটি পেশাদার উন্নয়ন রিপোর্টিং এবং HR রেকর্ডের জন্য বিশেষভাবে কার্যকর।

এমন সফটওয়্যার যার সোর্স কোড (এটি কাজ করানোর অন্তর্নিহিত নির্দেশাবলী) যে কারও পড়া, অধ্যয়ন ও শেখার জন্য সর্বজনীনভাবে উপলব্ধ। ওপেন-সোর্স প্রকল্পগুলো সাধারণত যে কাউকে উন্নতির পরামর্শ দিতে, বাগ রিপোর্ট করতে, এবং অবদান রাখতেও অনুমতি দেয়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo-র কোড ওপেন সোর্স (MIT License-এর অধীনে GitHub-এ উপলব্ধ)। এর মানে: আপনি ঠিক দেখতে পারেন প্ল্যাটফর্মটি কীভাবে কাজ করে; আপনি যাচাই করতে পারেন যে লুকানো বা সমস্যাজনক কিছু নেই; সম্প্রদায় উন্নতিতে অবদান রাখতে পারে; এবং অন্যান্য প্রতিষ্ঠান এই পদ্ধতি থেকে শিখতে পারে। *শিক্ষামূলক কন্টেন্টের* একটি ভিন্ন লাইসেন্স আছে (CC BY-NC-ND 4.0), কিন্তু *কোড* সম্পূর্ণ উন্মুক্ত।

## P

### PWA (Progressive Web App)

একটি ওয়েবসাইট যা আপনার ফোন বা কম্পিউটারে ইনস্টল করা একটি অ্যাপের মতো আচরণ করতে পারে। একটি PWA অফলাইনে কাজ করতে পারে, বিজ্ঞপ্তি পাঠাতে পারে, ধীর সংযোগে দ্রুত লোড হতে পারে, এবং আপনার হোম স্ক্রিনে যোগ করা যেতে পারে — এই সবই কোনো অ্যাপ স্টোর থেকে ডাউনলোড না করেই।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo একটি PWA হিসেবে তৈরি। এর মানে আপনি অনির্ভরযোগ্য ইন্টারনেট সহ এলাকায় এটি ব্যবহার করতে পারেন: আপনি আগে যে কন্টেন্ট লোড করেছেন তা ক্যাশ করা (স্থানীয়ভাবে সংরক্ষিত) হয় এবং অফলাইনে উপলব্ধ থাকে। আপনি একটি নিয়মিত অ্যাপের মতো দ্রুত অ্যাক্সেসের জন্য আপনার ফোনের হোম স্ক্রিনেও ImpactMojo যোগ করতে পারেন — তবে বেশি স্টোরেজ না নিয়ে বা অ্যাপ স্টোর থেকে আপডেট ছাড়াই।

## R

### Responsive Design

একটি ওয়েব ডিজাইন পদ্ধতি যেখানে পৃষ্ঠাগুলো দেখা ডিভাইসের স্ক্রিন আকারের উপর ভিত্তি করে স্বয়ংক্রিয়ভাবে তাদের লেআউট সামঞ্জস্য করে। একই পৃষ্ঠা একটি ফোন, একটি ট্যাবলেট, এবং একটি ডেস্কটপ মনিটরে ভিন্ন (কিন্তু সমানভাবে ব্যবহারযোগ্য) দেখায়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** অনেক উন্নয়ন পেশাদার মোবাইল ফোনে ImpactMojo অ্যাক্সেস করেন — কখনো ফোন তাদের প্রাথমিক ডিভাইস, কখনো তারা মাঠে থাকেন এবং সেটিই তাদের কাছে থাকে। Responsive design মানে প্রতিটি কোর্স, হ্যান্ডআউট, ল্যাব, এবং গেম আপনি যে ডিভাইসই ব্যবহার করুন তাতে কাজ করে। শেখার বা পরিচালনার জন্য আপনার ল্যাপটপের প্রয়োজন নেই।

## S

### Skill (Claude AI Context)

Claude-এর মতো AI সহকারীদের প্রসঙ্গে, একটি **Skill** হলো একটি পূর্ব-নির্মিত কমান্ড যা একটি নির্দিষ্ট, কাঠামোবদ্ধ কাজ সম্পাদন করে। আপনি একটি কমান্ড টাইপ করে (যেমন "/analyze-program") একটি skill চালু করেন, এবং AI একটি নির্ধারিত ধাপের ক্রম অনুসরণ করে — প্রশ্ন জিজ্ঞাসা, ডেটা পুনরুদ্ধার, বিশ্লেষণ কাঠামোবদ্ধ করা।

**এভাবে ভাবুন:** একটি skill একটি রেসিপির মতো। প্রতিবার একটি কর্মসূচি মূল্যায়ন বা সাহিত্য পর্যালোচনা করতে চাইলে শুরু থেকে শুরু করার পরিবর্তে, আপনি একটি skill চালু করেন যা ধাপে ধাপে প্রক্রিয়ার মধ্য দিয়ে আপনাকে নিয়ে যায়।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** ImpactMojo উন্নয়ন গবেষণা কাজের জন্য কাস্টম Skills তৈরি করছে — কর্মসূচি মূল্যায়ন, প্রমাণ পর্যালোচনা, নির্দেশক বিশ্লেষণ, এবং আরও অনেক কিছু। যাদের prompt engineering-এর পটভূমি নেই, সেই পেশাদারদের জন্য AI সরঞ্জামগুলোকে ব্যবহারিক ও সহজলভ্য করতে এগুলো ডিজাইন করা হয়েছে। উপলব্ধ skills [Dataverse](dataverse-guide.md) তালিকাভুক্ত করে।

### South Asian Context

ImpactMojo-তে **ভারত, বাংলাদেশ, নেপাল, শ্রীলঙ্কা**, এবং বৃহত্তর দক্ষিণ এশীয় অঞ্চল থেকে নেওয়া উদাহরণ, কেস স্টাডি, ডেটা, এবং পরিস্থিতি ব্যবহার করার একটি ইচ্ছাকৃত ডিজাইন পছন্দ।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** উন্নয়নের জন্য বেশিরভাগ অনলাইন শিক্ষার প্ল্যাটফর্ম পূর্ব আফ্রিকা, লাতিন আমেরিকা, বা গ্লোবাল নর্থ থেকে উদাহরণ ব্যবহার করে। এগুলো মূল্যবান, কিন্তু দক্ষিণ এশীয় পরিবেশে কাজ করা পেশাদারদের সাথে এগুলো সবসময় অনুরণিত হয় না — যেখানে শাসন কাঠামো, সামাজিক গতিশীলতা, ডেটা সিস্টেম, এবং কর্মসূচির ধরন তাদের নিজস্ব বৈশিষ্ট্য আছে। ImpactMojo-র কন্টেন্ট সেইসব মানুষের জন্য তৈরি যারা এই অঞ্চলে কাজ করেন এবং এমন সামগ্রী প্রয়োজন যা তারা প্রতিদিন যে বাস্তবতার মুখোমুখি হন তা প্রতিফলিত করে। একটি কোর্স যখন একটি টিকাকরণ কর্মসূচি নিয়ে আলোচনা করে, তখন এটি ভারতের সর্বজনীন টিকাকরণ কর্মসূচির উল্লেখ করে, কোনো সাধারণ কাল্পনিক নয়।

### Supabase

একটি ওপেন-সোর্স প্ল্যাটফর্ম যা ওয়েব অ্যাপ্লিকেশনের জন্য ডেটাবেস, প্রমাণীকরণ (লগইন), এবং স্টোরেজ পরিষেবা প্রদান করে। এটি সেই backend অবকাঠামো যা ImpactMojo-র ব্যবহারকারীর ডেটা সংরক্ষণ ও পরিচালনা করে।

**এভাবে ভাবুন:** ImpactMojo ওয়েবসাইট যদি সেই ভবন হয় যেখানে আপনি প্রবেশ করেন, তবে Supabase হলো কাউন্টারের পিছনের ফাইলিং সিস্টেম — এটি আপনার অ্যাকাউন্ট তথ্য সংরক্ষণ করে, মনে রাখে আপনি কোন কোর্স সম্পূর্ণ করেছেন, আপনার বুকমার্ক রাখে, এবং আপনার সার্টিফিকেট পরিচালনা করে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** আপনি কখনোই সরাসরি Supabase-এর সাথে যোগাযোগ করবেন না। কিন্তু আপনি যখন একটি অ্যাকাউন্ট তৈরি করেন, লগইন করেন, আপনার কোর্সের অগ্রগতি ট্র্যাক করেন, বা একটি সার্টিফিকেট অর্জন করেন — তখন Supabase-ই সেটি কাজ করায়। এটিও ওপেন সোর্স, যার মানে কোনো মালিকানাধীন লক-ইন নেই: প্রয়োজনে আপনার ডেটা অন্য একটি সিস্টেমে সরানো যেতে পারে।

## W

### WCAG (Web Content Accessibility Guidelines)

World Wide Web Consortium (W3C) দ্বারা তৈরি আন্তর্জাতিক মানদণ্ডের একটি সেট, যা সংজ্ঞায়িত করে কীভাবে প্রতিবন্ধী ব্যক্তিদের জন্য ওয়েব কন্টেন্ট অ্যাক্সেসযোগ্য করা যায়। WCAG রঙের বৈসাদৃশ্য (যাতে স্বল্প দৃষ্টিসম্পন্ন ব্যক্তিদের জন্য টেক্সট পঠনযোগ্য হয়), কীবোর্ড নেভিগেশন (যাতে যারা মাউস ব্যবহার করতে পারেন না তারাও নেভিগেট করতে পারেন), এবং ছবির জন্য বিকল্প টেক্সট (যাতে স্ক্রিন রিডার অন্ধ ব্যবহারকারীদের ছবি বর্ণনা করতে পারে) এর মতো বিষয়গুলো কভার করে।

**এটি আপনার কাজের জন্য কেন গুরুত্বপূর্ণ:** এর কোর্স, হ্যান্ডআউট, এবং সরঞ্জাম সবার জন্য ব্যবহারযোগ্য তা নিশ্চিত করতে ImpactMojo WCAG নির্দেশিকা অনুসরণ করে। আপনি যদি আপনার নিজস্ব ডিজিটাল সামগ্রী তৈরি করেন — ওয়েবসাইট, PDF, উপস্থাপনা — তবে WCAG হলো সেই মান যা লক্ষ্য করা উচিত। এটি তিনটি স্তরে সংগঠিত: A (ন্যূনতম), AA (প্রস্তাবিত), এবং AAA (আদর্শ)। বেশিরভাগ প্রতিষ্ঠান AA লক্ষ্য করে।
