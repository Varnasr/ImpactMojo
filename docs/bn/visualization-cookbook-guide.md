# Visualization Cookbook গাইড

## Visualization Cookbook কী?

Visualization Cookbook হল প্রোডাকশন-প্রস্তুত Python কোড সহ একটি **প্রশ্ন-চালিত চার্ট নির্বাচন সরঞ্জাম**। চার্ট গ্যালারি ব্রাউজ করে এবং কোন চার্ট ধরন আপনার তথ্যের জন্য উপযুক্ত তা অনুমান করার পরিবর্তে, আপনি একটি সহজ প্রশ্নের উত্তর দেন — "আমার তথ্য কোন গল্প বলে?" — এবং সঠিক চার্টের সাথে কার্যকর কোড পান যা আপনি তৎক্ষণাৎ কপি করে ব্যবহার করতে পারেন।

এতে **14টি চার্ট ধরন** অন্তর্ভুক্ত যা উন্নয়ন কাজের সবচেয়ে সাধারণ তথ্য-গল্পগুলি কভার করে।

**অ্যাক্সেস:** DevData Practice (Professional tier)-এর অংশ — [Visualization Cookbook খুলুন](https://impactmojo-devdata-pro.netlify.app/charts.html)

## এটি যে সমস্যার সমাধান করে

উন্নয়ন পেশাদাররা তথ্যে পূর্ণ প্রতিবেদন, প্রস্তাব এবং উপস্থাপনা তৈরি করেন — কিন্তু চার্টগুলি প্রায়শই সবচেয়ে দুর্বল অংশ। সাধারণ সমস্যা:

- **ভুল চার্ট ধরন** — যখন বার চার্ট আরও স্পষ্ট হত তখন পাই চার্ট ব্যবহার করা, অথবা যখন আপনি সময় দেখাচ্ছেন না তখন লাইন চার্ট ব্যবহার করা
- **এলোমেলো ভিজ্যুয়াল** — একটি চার্টে অনেক বেশি রঙ, লেবেল, বা তথ্য বিন্দু
- **শূন্য থেকে শুরু করা** — শুধু একটি ভালো চার্ট তৈরি করতে Excel-এ ঘণ্টার পর ঘণ্টা ব্যয় করা বা Python শেখার চেষ্টা করা
- **অসামঞ্জস্যপূর্ণ মান** — প্রতিটি দলের সদস্য এমন চার্ট তৈরি করেন যা দেখতে আলাদা

Visualization Cookbook প্রথমে আপনাকে একটি প্রশ্ন জিজ্ঞাসা করে এগুলির সমাধান করে: **আপনার তথ্য কী বলতে চাইছে?**

## এটি কীভাবে কাজ করে

### ধাপ 1: আপনার তথ্য-গল্প বেছে নিন

প্রতিটি চার্ট ছয় ধরনের প্রশ্নের মধ্যে একটির উত্তর দেয়:

| তথ্য-গল্প | আপনি কী দেখাচ্ছেন | উদাহরণ |
|-----------|-------------------|---------|
| **তুলনা** | জিনিসগুলি একে অপরের থেকে কীভাবে আলাদা | "কোন জেলায় সর্বোচ্চ টিকাকরণের হার?" |
| **বিতরণ** | একটি পরিসরে তথ্য কীভাবে ছড়িয়ে আছে | "আমাদের লক্ষ্য এলাকায় পরিবারের আয় কীভাবে বিতরিত?" |
| **সম্পর্ক** | দুটি চলক একে অপরের সাথে কীভাবে সম্পর্কিত | "শিক্ষা ব্যয় এবং শেখার ফলাফলের মধ্যে কি কোনো সম্পর্ক আছে?" |
| **গঠন** | একটি সম্পূর্ণকে কী তৈরি করে | "আমাদের বাজেটের কত অনুপাত প্রতিটি কর্মসূচি ক্ষেত্রে যায়?" |
| **সময় সিরিজ** | সময়ের সাথে কিছু কীভাবে পরিবর্তিত হয় | "গত 10 বছরে খর্বতার প্রকোপ কীভাবে পরিবর্তিত হয়েছে?" |
| **স্থানিক** | ভূগোল জুড়ে কিছু কীভাবে পরিবর্তিত হয় | "কোন রাজ্যগুলিতে সর্বোচ্চ দারিদ্র্যের হার?" |

### ধাপ 2: সঠিক চার্ট পান

আপনার তথ্য-গল্পের ভিত্তিতে, Cookbook এক বা একাধিক চার্ট ধরন সুপারিশ করে এবং আপনাকে দেখায়:
- একটি **নমুনা চার্ট** যাতে আপনি দেখতে পারেন এটি কেমন দেখায়
- **কখন এটি ব্যবহার করতে হবে** — এবং কখন নয়
- matplotlib এবং seaborn (প্রমিত ডেটা সায়েন্স লাইব্রেরি) ব্যবহার করে **প্রোডাকশন-প্রস্তুত Python কোড**

### ধাপ 3: কোড অভিযোজিত করুন

Python কোড কপি করুন, নমুনা তথ্য আপনার নিজের দিয়ে প্রতিস্থাপন করুন, এবং চালান। চার্টটি প্রকাশনা-প্রস্তুত — সঠিক লেবেল, পরিচ্ছন্ন ফরম্যাটিং, এবং পেশাদার স্টাইলিং।

## আমার কি Python জানা দরকার?

**অগত্যা নয়।** আপনি যদি Python কোড চালাতে পারেন (বা এমন একজন সহকর্মী থাকেন যিনি পারেন) তাহলে Cookbook সবচেয়ে উপযোগী, কিন্তু কোডিং জ্ঞান ছাড়াও:

- **চার্ট নির্বাচন নির্দেশনা নিজেই মূল্যবান।** কোন চার্ট ধরন ব্যবহার করতে হবে তা জানা অর্ধেক যুদ্ধ — তারপর আপনি এটি Excel, Google Sheets, বা আপনি যে কোনো সরঞ্জামে স্বচ্ছন্দ তাতে তৈরি করতে পারেন।
- **কোডটি টীকা-সহ।** মন্তব্যগুলি ব্যাখ্যা করে প্রতিটি লাইন কী করে, তাই মৌলিক Python দক্ষতা সম্পন্ন কেউ এটি সংশোধন করতে পারে।
- **ImpactMojo-এর Data & Technology courses মূল বিষয়গুলি শেখায়।** আপনি যদি তথ্য ভিজ্যুয়ালাইজেশনের জন্য Python শিখতে চান, তাহলে Data Visualization foundational course দিয়ে শুরু করুন।

## শিক্ষাবিদরা কীভাবে Cookbook ব্যবহার করতে পারেন

### তথ্য ভিজ্যুয়ালাইজেশন কর্মশালার জন্য
অংশগ্রহণকারীদের "আপনার তথ্য-গল্প বেছে নিন" কাঠামোর মধ্য দিয়ে নিয়ে যান। তাদের নিজস্ব তথ্য আনতে বলুন এবং একটি চার্ট ধরন বেছে নেওয়ার আগে এটি কোন গল্প বলে তা শনাক্ত করতে বলুন।

### প্রতিবেদন লেখার সেশনের জন্য
দলগুলি যখন প্রতিবেদন প্রস্তুত করছে, তখন চার্ট উপযুক্ত এবং স্পষ্ট তা নিশ্চিত করতে Cookbook ব্যবহার করুন। ছয়টি তথ্য-গল্প বিভাগ দলগুলিকে তারা কী যোগাযোগ করার চেষ্টা করছে তা ভাবতে সাহায্য করে।

### চার্ট সাক্ষরতা শেখানোর জন্য
এমনকি অংশগ্রহণকারীরা কোড না লিখলেও, Cookbook তাদের চার্ট সমালোচনামূলকভাবে পড়তে শেখায়। "এই চার্ট কোন তথ্য-গল্প বলছে? এটি কি সেই গল্পের জন্য সঠিক চার্ট ধরন?"

## পরামর্শ

- **তথ্য-গল্প দিয়ে শুরু করুন, চার্ট ধরন দিয়ে নয়।** "আমি একটি পাই চার্ট তৈরি করতে চাই" হল ভুল শুরুর বিন্দু। "আমি দেখাতে চাই আমাদের বাজেটের কত অনুপাত প্রতিটি কর্মসূচিতে যায়" হল সঠিক।
- **কম মানে বেশি।** সেরা চার্টগুলি একটি জিনিস স্পষ্টভাবে যোগাযোগ করে। আপনার চার্টের যদি একটি অনুচ্ছেদ ব্যাখ্যার প্রয়োজন হয়, তাহলে এটি সরল করুন।
- **তথ্য ভিজ্যুয়ালাইজেশনের উপর Handout-এর পাশাপাশি Cookbook ব্যবহার করুন।** হ্যান্ডআউট নীতিগুলি কভার করে; Cookbook বাস্তবায়ন প্রদান করে।
- **Python কোড Google Colab-এ কাজ করে।** আপনার যদি Python ইনস্টল না থাকে, তাহলে কোডটি [Google Colab](https://colab.research.google.com)-এ পেস্ট করুন — এটি বিনামূল্যে এবং আপনার ব্রাউজারে চলে।
