# Visualization Cookbook मार्गदर्शक

## Visualization Cookbook म्हणजे काय?

Visualization Cookbook हे उत्पादन-तयार Python कोडसह एक **प्रश्न-चालित चार्ट निवड साधन** आहे. चार्ट गॅलरी ब्राउझ करून आणि कोणता चार्ट प्रकार तुमच्या डेटासाठी योग्य आहे याचा अंदाज लावण्याऐवजी, तुम्ही एका सोप्या प्रश्नाचे उत्तर देता — "माझा डेटा कोणती कथा सांगतो?" — आणि तुम्हाला योग्य चार्टसह कार्यरत कोड मिळतो जो तुम्ही लगेच कॉपी करून वापरू शकता.

यात विकासकार्यातील सर्वात सामान्य डेटा कथा समाविष्ट करणारे **14 चार्ट प्रकार** आहेत.

**प्रवेश:** DevData Practice (Professional tier) चा भाग — [Visualization Cookbook उघडा](https://impactmojo-devdata-pro.netlify.app/charts.html)

---

## हे ज्या समस्येचे निराकरण करते

विकास व्यावसायिक डेटाने भरलेले अहवाल, प्रस्ताव आणि सादरीकरणे तयार करतात — परंतु चार्ट अनेकदा सर्वात कमकुवत भाग असतात. सामान्य समस्या:

- **चुकीचा चार्ट प्रकार** — जेव्हा बार चार्ट अधिक स्पष्ट असेल तेव्हा पाई चार्ट वापरणे, किंवा जेव्हा तुम्ही वेळ दाखवत नसता तेव्हा लाइन चार्ट वापरणे
- **गोंधळलेले दृश्य** — एका चार्टवर खूप जास्त रंग, लेबले, किंवा डेटा बिंदू
- **सुरुवातीपासून सुरू करणे** — फक्त एक चांगला चार्ट बनवण्यासाठी Excel मध्ये तासन्तास घालवणे किंवा Python शिकण्याचा प्रयत्न करणे
- **विसंगत गुणवत्ता** — प्रत्येक संघ सदस्य वेगळे दिसणारे चार्ट तयार करतो

Visualization Cookbook हे प्रथम एक प्रश्न विचारून सोडवते: **तुमचा डेटा काय सांगू इच्छितो?**

## हे कसे कार्य करते

### पायरी 1: तुमची डेटा कथा निवडा

प्रत्येक चार्ट सहा प्रकारच्या प्रश्नांपैकी एकाचे उत्तर देतो:

| डेटा कथा | तुम्ही काय दाखवत आहात | उदाहरण |
|-----------|-------------------|---------|
| **तुलना** | गोष्टी एकमेकांपेक्षा कशा वेगळ्या आहेत | "कोणत्या जिल्ह्यात सर्वाधिक लसीकरण दर आहे?" |
| **वितरण** | एका श्रेणीमध्ये डेटा कसा पसरला आहे | "आमच्या लक्ष्य क्षेत्रात कौटुंबिक उत्पन्न कसे वितरित आहे?" |
| **संबंध** | दोन चल एकमेकांशी कसे संबंधित आहेत | "शिक्षण खर्च आणि शिक्षण परिणामांदरम्यान काही सहसंबंध आहे का?" |
| **रचना** | एक संपूर्ण कशामुळे बनते | "आमच्या अंदाजपत्रकाचा कोणता हिस्सा प्रत्येक कार्यक्रम क्षेत्रात जातो?" |
| **कालमालिका** | कालांतराने काहीतरी कसे बदलते | "गेल्या 10 वर्षांत खुंटलेपणाचे प्रमाण कसे बदलले आहे?" |
| **स्थानिक** | भूगोलानुसार काहीतरी कसे बदलते | "कोणत्या राज्यांत सर्वाधिक दारिद्र्य दर आहे?" |

### पायरी 2: योग्य चार्ट मिळवा

तुमच्या डेटा कथेच्या आधारे, Cookbook एक किंवा अधिक चार्ट प्रकारांची शिफारस करते आणि तुम्हाला दाखवते:
- एक **नमुना चार्ट** जेणेकरून तो कसा दिसतो हे तुम्ही पाहू शकता
- **तो कधी वापरावा** — आणि कधी वापरू नये
- matplotlib आणि seaborn (प्रमाणित डेटा सायन्स लायब्ररी) वापरून **उत्पादन-तयार Python कोड**

### पायरी 3: कोड अनुकूलित करा

Python कोड कॉपी करा, नमुना डेटाला तुमच्या स्वतःच्या डेटाने बदला, आणि चालवा. चार्ट प्रकाशन-तयार आहे — योग्य लेबले, स्वच्छ स्वरूपण, आणि व्यावसायिक शैली.

## 14 चार्ट प्रकार

| चार्ट | कशासाठी सर्वोत्तम | डेटा कथा |
|-------|---------|-----------|
| बार चार्ट | श्रेणींची तुलना करणे | तुलना |
| समूहित बार चार्ट | समूहांमध्ये श्रेणींची तुलना करणे | तुलना |
| क्षैतिज बार चार्ट | लांब नावांसह अनेक श्रेणी | तुलना |
| लाइन चार्ट | कालांतराने कल | कालमालिका |

| स्टॅक्ड बार चार्ट | श्रेणींमध्ये एका संपूर्णाचे भाग | रचना |
| हीटमॅप | द्विमितीय डेटातील नमुने | संबंध |

| स्लोप चार्ट | दोन कालबिंदूंमधील बदल | तुलना + वेळ |

## मला Python माहीत असणे आवश्यक आहे का?

**अनिवार्यपणे नाही.** तुम्ही Python कोड चालवू शकत असाल (किंवा चालवू शकणारा सहकारी असेल) तर Cookbook सर्वात उपयुक्त आहे, परंतु कोडिंग ज्ञानाशिवायही:

- **चार्ट निवड मार्गदर्शन स्वतःच मौल्यवान आहे.** कोणता चार्ट प्रकार वापरायचा हे जाणून घेणे ही अर्धी लढाई आहे — मग तुम्ही तो Excel, Google Sheets, किंवा तुम्हाला सोयीस्कर असलेल्या कोणत्याही साधनात तयार करू शकता.
- **कोड टीप-सहित आहे.** प्रत्येक ओळ काय करते हे टिप्पण्या स्पष्ट करतात, त्यामुळे मूलभूत Python कौशल्य असलेली व्यक्ती तो सुधारित करू शकते.
- **ImpactMojo चे Data & Technology courses मूलभूत गोष्टी शिकवतात.** तुम्हाला डेटा व्हिज्युअलायझेशनसाठी Python शिकायचे असल्यास, Data Visualization foundational course पासून सुरुवात करा.

## शिक्षक Cookbook कसे वापरू शकतात

### डेटा व्हिज्युअलायझेशन कार्यशाळांसाठी
सहभागींना "तुमची डेटा कथा निवडा" चौकटीतून घेऊन जा. त्यांना त्यांचा स्वतःचा डेटा आणण्यास सांगा आणि चार्ट प्रकार निवडण्यापूर्वी तो कोणती कथा सांगतो हे ओळखण्यास सांगा.

### अहवाल लेखन सत्रांसाठी
जेव्हा संघ अहवाल तयार करत असतात, तेव्हा चार्ट योग्य आणि स्पष्ट आहेत याची खात्री करण्यासाठी Cookbook वापरा. सहा डेटा कथा श्रेणी संघांना ते काय संवाद साधण्याचा प्रयत्न करत आहेत याबद्दल विचार करण्यास मदत करतात.

### चार्ट साक्षरता शिकवण्यासाठी
सहभागी कोड लिहिणार नसले तरीही, Cookbook त्यांना चार्ट चिकित्सकपणे वाचण्यास शिकवते. "हा चार्ट कोणती डेटा कथा सांगत आहे? त्या कथेसाठी हा योग्य चार्ट प्रकार आहे का?"

## टिपा

- **चार्ट प्रकाराने नव्हे, डेटा कथेने सुरुवात करा.** "मला पाई चार्ट बनवायचा आहे" हा चुकीचा प्रारंभ बिंदू आहे. "आमच्या अंदाजपत्रकाचा कोणता हिस्सा प्रत्येक कार्यक्रमात जातो हे मला दाखवायचे आहे" हा योग्य आहे.
- **कमी म्हणजे जास्त.** सर्वोत्तम चार्ट एक गोष्ट स्पष्टपणे संवाद साधतात. तुमच्या चार्टला स्पष्टीकरणाच्या एका परिच्छेदाची गरज असल्यास, तो सोपा करा.
- **डेटा व्हिज्युअलायझेशनवरील Handout सोबत Cookbook वापरा.** हँडआउट तत्त्वे समाविष्ट करते; Cookbook अंमलबजावणी प्रदान करते.
- **Python कोड Google Colab मध्ये कार्य करतो.** तुमच्याकडे Python स्थापित नसल्यास, कोड [Google Colab](https://colab.research.google.com) मध्ये पेस्ट करा — तो विनामूल्य आहे आणि तुमच्या ब्राउझरमध्ये चालतो.
