# Glossary

ImpactMojo वापरताना किंवा विकास क्षेत्रात डिजिटल साधनांसोबत काम करताना तुम्हाला भेटू शकणाऱ्या तांत्रिक संज्ञांसाठी एक सोप्या-भाषेतील मार्गदर्शिका. प्रत्येक व्याख्या अशा हुशार, अनुभवी व्यावसायिकांसाठी लिहिली आहे जे योगायोगाने तंत्रज्ञान क्षेत्रात काम करत नाहीत.

---

## A

### Accessibility (a11y)

संकेतस्थळे, दस्तऐवज आणि साधने अशा प्रकारे डिझाइन करण्याची प्रथा की ती प्रत्येकजण वापरू शकेल — ज्यात दृष्टिदोष, श्रवणक्षमता गमावलेले, हालचालीची अक्षमता, किंवा संज्ञानात्मक भिन्नता असलेल्या लोकांचा समावेश आहे. "a11y" हे संक्षिप्त रूप एक शॉर्टहँड आहे: "a", नंतर ११ अक्षरे, नंतर "y".

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जर तुम्ही प्रशिक्षण साहित्य, अहवाल, किंवा डिजिटल मजकूर तयार करत असाल, तर सुलभता हे सुनिश्चित करते की तुमच्या संघातील किंवा तुमच्या समुदायातील कोणीही वगळला जाणार नाही. हे मजकूर *सर्वांसाठी* अधिक चांगला देखील बनवते — स्पष्ट रचना, चांगला कॉन्ट्रास्ट, अधिक वाचनीय मजकूर. ImpactMojo सुलभता लक्षात घेऊन तयार केले आहे, जे WCAG मार्गदर्शक तत्त्वांचे पालन करते (खाली पहा).

### API (Application Programming Interface)

एका सॉफ्टवेअरने दुसऱ्याकडून माहिती मागवण्याचा एक संरचित मार्ग. जेव्हा तुम्ही एखाद्या संकेतस्थळाला भेट देता, तेव्हा तुमचा ब्राउझर मूलतः मजकूर मिळवण्यासाठी साइटचा API वापरत असतो. पण ही संज्ञा सहसा *डेटा API* ला संदर्भित करते — अशा सेवा ज्या तुम्हाला विशिष्ट डेटा मागवू देतात (उदाहरणार्थ, "२०१५ ते २०२३ पर्यंत भारताचा बालमृत्यू दर") आणि नेमका तोच, संगणक काम करू शकेल अशा स्वरूपात परत देतात.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जर तुम्हाला नियमितपणे World Bank, WHO, किंवा भारतीय जनगणना यांसारख्या संस्थांकडून डेटा हवा असेल, तर API तुम्हाला संकेतस्थळांवर हाताने नेव्हिगेट न करता आणि फायली डाउनलोड न करता नेमके तुम्हाला हवे ते मिळवू देतात. अनेक API मोफत असतात आणि त्यांचे सोपे वेब-आधारित इंटरफेस असतात — ते वापरण्यासाठी तुम्हाला कोड लिहिण्याची गरज नाही, जरी कोड त्यांना अधिक शक्तिशाली बनवतो. कोणती संसाधने API देतात हे ImpactMojo [Dataverse](dataverse-guide.md) ओळखते.

## C

### CC BY-NC-ND 4.0

एक Creative Commons परवाना — विशेषतः, **Attribution-NonCommercial-NoDerivatives 4.0 International**. हाच तो परवाना आहे जो ImpactMojo च्या शैक्षणिक मजकुरास (अभ्यासक्रम, हँडआउट्स, गेम्स, लॅब्स) व्यापतो.

प्रत्येक भागाचा अर्थ येथे आहे:

- **BY** — मजकूर सामायिक करताना तुम्हाला ImpactMojo ला श्रेय द्यावे लागेल
- **NC (NonCommercial)** — तुम्ही मजकूर विकू शकत नाही किंवा व्यावसायिक हेतूंसाठी वापरू शकत नाही
- **ND (NoDerivatives)** — तुम्ही मजकूर सुधारित करून सुधारित आवृत्ती वितरित करू शकत नाही

**तुम्ही *काय* करू शकता:** तुमच्या संघासोबत हँडआउट्स सामायिक करा, तुमच्या प्रशिक्षण सत्रांमध्ये अभ्यासक्रम वापरा, तुमच्या संकेतस्थळावरून मजकुराला लिंक द्या, कार्यशाळांसाठी साहित्य छापा — हे सर्व मोफत, जोपर्यंत तुम्ही ImpactMojo ला श्रेय देता आणि त्यासाठी शुल्क आकारत नाही किंवा ते बदलत नाही.

**तुम्ही *काय* करू शकत नाही:** छापील प्रती विकणे, मजकूर स्वतःचा ब्रँड म्हणून पुनर्ब्रँड करणे, किंवा वितरणासाठी सुधारित आवृत्त्या तयार करणे.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** हा परवाना ImpactMojo चा मजकूर मोफत आणि सुसंगत ठेवतो, त्याचबरोबर तुम्हाला तुमच्या कार्यक्रमांमध्ये आणि अध्यापनात तो व्यापकपणे वापरू देतो.

### CDN (Content Delivery Network)

जगभरातील अनेक ठिकाणी पसरलेल्या सर्व्हर्सचे एक नेटवर्क. जेव्हा तुम्ही CDN वापरणाऱ्या संकेतस्थळाला भेट देता, तेव्हा मजकूर तुमच्या भौगोलिकदृष्ट्या सर्वात जवळच्या सर्व्हरवरून दिला जातो, दूर असू शकणाऱ्या एका मध्यवर्ती ठिकाणावरून नव्हे.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** यामुळेच दक्षिण आशियातील ग्रामीण भागात मंद कनेक्शनवरही ImpactMojo पाने बऱ्यापैकी वेगाने लोड होतात. प्रत्येक विनंती दुसऱ्या देशातील सर्व्हरकडे जाण्याऐवजी, CDN जवळच्या ठिकाणावरून मजकूर देतो. याचा लाभ घेण्यासाठी तुम्हाला काहीही करण्याची गरज नाही — हे आपोआप कार्य करते.

### CSV (Comma-Separated Values)

सारणीबद्ध डेटासाठी एक सोपे फाइल स्वरूप — स्प्रेडशीटसारखे, पण साध्या मजकुराच्या रूपात साठवलेले. प्रत्येक ओळ एक रेषा असते, आणि प्रत्येक स्तंभ स्वल्पविरामाने वेगळा केला जातो. CSV फाइल Excel, Google Sheets, किंवा कोणत्याही डेटा साधनात उघडता येते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** डेटा सामायिक करण्यासाठी CSV हे सर्वात सार्वत्रिक स्वरूप आहे. जर कोणी तुम्हाला डेटासेट पाठवला, तर तो CSV असण्याची चांगली शक्यता आहे. जर तुम्हाला यंत्रणांमध्ये डेटा हलवायचा असेल (उदाहरणार्थ, सर्वेक्षण साधनातून सांख्यिकीय प्रोग्राममध्ये), तर CSV ही सहसा दोघेही बोलणारी समान भाषा असते. ImpactMojo Dataverse मधील बहुतेक संसाधने CSV स्वरूपात डेटा देतात.

## E

### Edge Function

कोडचा एक छोटा तुकडा जो विनंती करणाऱ्या व्यक्तीच्या भौगोलिकदृष्ट्या जवळ असलेल्या सर्व्हरवर चालतो, हजारो किलोमीटर दूर असू शकणाऱ्या मध्यवर्ती सर्व्हरवर नव्हे. "Edge" म्हणजे नेटवर्कची कड — वापरकर्त्याच्या सर्वात जवळचा बिंदू.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo काही वैशिष्ट्यांसाठी (जसे की लॉगिन आणि प्रमाणपत्र निर्मिती) edge functions वापरते जेणेकरून तुम्ही कुठेही असलात तरी ते जलद प्रतिसाद देतील. जर तुम्ही पटना किंवा चितगाँगमध्ये असाल, तर फंक्शन दूरच्या डेटा सेंटरकडे फेरीची वाट पाहण्याऐवजी जवळच्या सर्व्हरवर चालते. हे होताना तुम्हाला दिसणार नाही — फक्त गोष्टी अधिक वेगवान वाटतील.

## G

### Git / GitHub

**Git** ही एक आवृत्ती नियंत्रण प्रणाली आहे — असे सॉफ्टवेअर जे कालांतराने फायलींच्या संचात केलेल्या प्रत्येक बदलाचा मागोवा घेते. याला Microsoft Word मधील "Track Changes" सारखे समजा, पण शेकडो फायली असलेल्या संपूर्ण प्रकल्पांसाठी. प्रत्येक बदल नोंदवला जातो: कोणी केला, केव्हा, आणि नेमके काय बदलले. तुम्ही कोणत्याही वेळी कोणत्याही मागील आवृत्तीकडे परत जाऊ शकता.

**GitHub** ही एक संकेतस्थळ आहे जिथे लोक Git ने व्यवस्थापित केलेले प्रकल्प साठवतात आणि सामायिक करतात. इथेच ImpactMojo चा कोड राहतो, आणि इथेच योगदानकर्ते बदल सुचवू शकतात किंवा समस्या नोंदवू शकतात.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जर तुम्हाला ImpactMojo मध्ये योगदान द्यायचे असेल (अनुवाद, मजकूर, कोड), तर तुम्ही GitHub सोबत संवाद साधाल. जरी तुम्ही योगदान दिले नाही, तरी ImpactMojo GitHub वर आहे हे समजणे म्हणजे हे व्यासपीठ नेमके कसे तयार झाले आहे हे तुम्ही पाहू शकता — हे सर्व सार्वजनिक आहे.

## H

### HTML / CSS / JavaScript

तुम्ही भेट देता त्या प्रत्येक वेब पानाला बनवणाऱ्या तीन मूळ तंत्रज्ञाने:

- **HTML** (HyperText Markup Language) — रचना आणि मजकूर. पानावर काय आहे हे ते परिभाषित करते: शीर्षके, परिच्छेद, प्रतिमा, लिंक्स.
- **CSS** (Cascading Style Sheets) — दिसणे. गोष्टी कशा दिसतात हे ते परिभाषित करते: रंग, फॉन्ट, अंतर, मांडणी.
- **JavaScript** — वर्तन. हे पाने परस्परसंवादी बनवते: तुमची उत्तरे तपासणाऱ्या प्रश्नमंजुषा, अद्यतनित होणारे तक्ते, उघडणारे आणि बंद होणारे मेनू.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo हे फ्रंटएंडवर या तीन तंत्रज्ञानांनी बनलेले आहे आणि बाकी काही नाही — कोणतेही गुंतागुंतीचे frameworks किंवा build साधने नाहीत. याचा अर्थ ते जलद लोड होते, कोणत्याही उपकरणावर कार्य करते, आणि ऑफलाइन दिले जाऊ शकते. एखादे वैशिष्ट्य कसे कार्य करते हे जर तुम्हाला कधी समजून घ्यायचे असेल, तर पानाचा स्रोत पाहिल्यास तुम्हाला वाचनीय HTML, CSS, आणि JavaScript दिसेल.

### HTTPS / SSH

इंटरनेटवर सुरक्षित संप्रेषणासाठी दोन प्रोटोकॉल (पद्धती):

- **HTTPS** (HyperText Transfer Protocol Secure) — HTTP ची सुरक्षित आवृत्ती, जो प्रोटोकॉल तुमचा ब्राउझर वेब पाने लोड करण्यासाठी वापरतो. जेव्हा तुम्हाला तुमच्या ब्राउझरच्या पत्ता-पट्टीत टाळ्याचे चिन्ह दिसते, तेव्हा तुम्ही HTTPS वापरत आहात. याचा अर्थ तुमच्या उपकरण आणि संकेतस्थळादरम्यान प्रवास करणारा डेटा एन्क्रिप्टेड आहे — मध्ये कोणीही तो वाचू शकत नाही.
- **SSH** (Secure Shell) — दूरस्थ संगणकांशी सुरक्षितपणे जोडण्यासाठी आणि त्यांचे व्यवस्थापन करण्यासाठी एक प्रोटोकॉल. डेव्हलपर सर्व्हर्समध्ये प्रवेश करण्यासाठी आणि GitHub वर कोड पुश करण्यासाठी हा वापरतात.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo सर्व कनेक्शनसाठी HTTPS वापरते, याचा अर्थ तुमची लॉगिन क्रेडेन्शियल्स, प्रगती डेटा, आणि वैयक्तिक माहिती प्रवासादरम्यान एन्क्रिप्टेड राहते. कॅफे, विमानतळ, किंवा सामायिक कार्यालयीन जागांमधील सार्वजनिक Wi-Fi नेटवर्कवर हे विशेषतः महत्त्वाचे आहे.

## J

### JWT (JSON Web Token)

एक संक्षिप्त, सुरक्षित टोकन (एन्कोड केलेल्या डेटाचा एक छोटा तुकडा) जे एखादे संकेतस्थळ तुम्ही लॉग इन केल्यानंतर तुमच्या ब्राउझरला पाठवते. प्रत्येक वेळी तुम्ही नवीन पानावर जाता किंवा डेटाची विनंती करता, तेव्हा तुमचा ब्राउझर हे टोकन परत पाठवून सिद्ध करतो की तुम्हीच ती व्यक्ती आहात जिने लॉग इन केले होते — तुमचा पासवर्ड पुन्हा पाठवण्याची गरज न पडता.

**याचा असा विचार करा:** जेव्हा तुम्ही हॉटेलमध्ये चेक इन करता, तेव्हा तुम्हाला एक रूम की कार्ड मिळते. तुम्ही प्रत्येक वेळी तुमच्या खोलीत जाताना तुमचे ओळखपत्र दाखवत नाही — फक्त कार्ड टॅप करता. JWT संकेतस्थळांसाठी अगदी याच पद्धतीने कार्य करते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जेव्हा तुम्ही ImpactMojo खाते तयार करून लॉग इन करता, तेव्हा पानांदरम्यान फिरताना तुम्हाला लॉग इन ठेवणारे JWT असते. तेच हे सुनिश्चित करते की तुमची प्रगती, बुकमार्क्स, आणि प्रमाणपत्रे दुसऱ्या कोणाची नव्हे तर *तुमचीच* आहेत. टोकन एका ठराविक कालावधीनंतर कालबाह्य होते, त्यामुळे कोणी ते पकडले तरी ते जास्त काळ काम करणार नाही.

## M

### MCP Server (Model Context Protocol)

AI सहाय्यकांना (जसे की Claude) बाह्य डेटा स्रोत आणि सेवांशी जोडण्याचा एक प्रमाणित मार्ग. MCP Server एक पूल म्हणून कार्य करतो: AI सहाय्यक MCP कनेक्शनद्वारे विनंती पाठवतो, आणि सर्व्हर जोडलेल्या स्रोताकडून खरा, सध्याचा डेटा मिळवतो.

**याचा असा विचार करा:** कल्पना करा की तुमच्या संशोधन सहाय्यकाकडे एका विशिष्ट डेटाबेसचे लायब्ररी कार्ड आहे. तुम्हाला स्वतः लायब्ररीत जाण्याची गरज न पडता ते तुमच्यासाठी माहिती शोधू शकतात. MCP Server हेच ते लायब्ररी कार्ड आहे — ते AI सहाय्यकाला एका विशिष्ट डेटा स्रोतापर्यंत अधिकृत प्रवेश देते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** विकास संशोधनात AI साधने जसजशी अधिक सामान्य होत आहेत, तसतसे MCP Server तुम्हाला नैसर्गिक संभाषणाद्वारे विश्वसनीय, अधिकृत डेटापर्यंत पोहोचू देतात. एखाद्या गुंतागुंतीच्या सरकारी डेटा पोर्टलवर नेव्हिगेट करण्याऐवजी, तुम्ही तुमच्या AI सहाय्यकाला एक प्रश्न विचारून खरा डेटा परत मिळवू शकता. विकास डेटासाठी उपलब्ध MCP Server ImpactMojo [Dataverse](dataverse-guide.md) सूचीबद्ध करते.

## N

### Netlify

एक वेब होस्टिंग व्यासपीठ — ती सेवा जी ImpactMojo चे संकेतस्थळ तुमच्या ब्राउझरला देते. जेव्हा तुम्ही impactmojo.in ला भेट देता, तेव्हा Netlify ही पाने वितरित करणारी पायाभूत सुविधा आहे.

**याचा असा विचार करा:** जर ImpactMojo एक लायब्ररी असेल, तर Netlify ही ती इमारत आहे जिथे लायब्ररी आहे. ते पानांचे प्रत्यक्ष वितरण हाताळते, साइट चोवीस तास उपलब्ध ठेवते, आणि त्याच्या CDN द्वारे HTTPS सुरक्षा आणि जलद लोडिंग यांसारख्या गोष्टींचे व्यवस्थापन करते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** तुम्हाला Netlify बद्दल थेट विचार करण्याची गरज जवळजवळ कधीच पडणार नाही. पण जर तुम्ही पाहिले की साइट जलद लोड होत आहे, उपलब्ध राहत आहे, आणि मोबाइलवर चांगले कार्य करत आहे — तर ते अंशतः Netlify ची पायाभूत सुविधा कार्यरत आहे. ImpactMojo च्या योगदानकर्त्यांनाही याचा फायदा होतो कारण Netlify तैनाती सोपी करते: कोडमधील बदल आपोआप थेट साइटवर प्रतिबिंबित होतात.

## O

### Open Badges

**सत्यापनयोग्य डिजिटल प्रमाणपत्रे आणि सनदांसाठी** एक W3C (World Wide Web Consortium) मानक. Open Badge ही एक डिजिटल प्रतिमा आहे ज्यात एम्बेड केलेला मेटाडेटा असतो — ती कोणी मिळवली, कोणी जारी केली, कोणते निकष पूर्ण झाले, आणि केव्हा. हा मेटाडेटा कोणीही स्वतंत्रपणे सत्यापित करू शकतो.

**याचा असा विचार करा:** कागदी प्रमाणपत्राची फोटोकॉपी काढता येते किंवा ते बनावट बनवता येते. Open Badge हे अंगभूत सत्यापन प्रणाली असलेल्या प्रमाणपत्रासारखे आहे — कोणीही त्यावर क्लिक करून ते खरे आहे याची पुष्टी करू शकतो.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** जेव्हा तुम्ही ImpactMojo अभ्यासक्रम पूर्ण करून प्रमाणपत्र मिळवता, तेव्हा ते Open Badge म्हणून जारी केले जाते. तुम्ही ते LinkedIn वर सामायिक करू शकता, CV मध्ये समाविष्ट करू शकता, किंवा तुमच्या संस्थेला दाखवू शकता — आणि त्यावर क्लिक करणारा कोणीही सत्यापित करू शकतो की तुम्ही खरोखर अभ्यासक्रम पूर्ण केला आहे. हे व्यावसायिक विकास अहवाल आणि HR नोंदींसाठी विशेषतः उपयुक्त आहे.

### Open Source

असे सॉफ्टवेअर ज्याचा स्रोत कोड (ते कार्य करण्यामागील मूलभूत सूचना) कोणालाही वाचण्यासाठी, अभ्यासण्यासाठी, आणि त्यातून शिकण्यासाठी सार्वजनिकरित्या उपलब्ध आहे. ओपन-सोर्स प्रकल्प सहसा कोणालाही सुधारणा सुचवण्याची, बग नोंदवण्याची, आणि योगदान देण्याचीही परवानगी देतात.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo चा कोड ओपन सोर्स आहे (MIT License अंतर्गत GitHub वर उपलब्ध). याचा अर्थ: व्यासपीठ नेमके कसे कार्य करते हे तुम्ही पाहू शकता; काहीही लपवलेले किंवा समस्याजनक नाही याची तुम्ही पडताळणी करू शकता; समुदाय सुधारणांमध्ये योगदान देऊ शकतो; आणि इतर संस्था या दृष्टिकोनातून शिकू शकतात. *शैक्षणिक मजकुराचा* वेगळा परवाना आहे (CC BY-NC-ND 4.0), पण *कोड* पूर्णपणे खुला आहे.

## P

### PWA (Progressive Web App)

असे संकेतस्थळ जे तुमच्या फोन किंवा संगणकावर स्थापित केलेल्या ॲपसारखे वागू शकते. PWA ऑफलाइन कार्य करू शकते, सूचना पाठवू शकते, मंद कनेक्शनवर जलद लोड होऊ शकते, आणि तुमच्या होम स्क्रीनवर जोडले जाऊ शकते — हे सर्व ॲप स्टोअरवरून डाउनलोड न करता.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo हे PWA म्हणून तयार केले आहे. याचा अर्थ तुम्ही अविश्वसनीय इंटरनेट असलेल्या भागात ते वापरू शकता: तुम्ही आधी लोड केलेला मजकूर कॅश (स्थानिक पातळीवर जतन) केला जातो आणि ऑफलाइन उपलब्ध असतो. तुम्ही नियमित ॲपप्रमाणे जलद प्रवेशासाठी ImpactMojo तुमच्या फोनच्या होम स्क्रीनवरही जोडू शकता — पण जास्त स्टोरेज न घेता किंवा ॲप स्टोअरवरून अद्यतनांची गरज न पडता.

## R

### Responsive Design

एक वेब डिझाइन दृष्टिकोन जिथे पाने ती पाहणाऱ्या उपकरणाच्या स्क्रीन आकारानुसार आपली मांडणी आपोआप समायोजित करतात. तेच पान फोन, टॅबलेट, आणि डेस्कटॉप मॉनिटरवर वेगळे (पण तितकेच वापरण्यायोग्य) दिसते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** अनेक विकास व्यावसायिक ImpactMojo मोबाइल फोनवर वापरतात — कधी फोन हेच त्यांचे प्राथमिक उपकरण असते, कधी ते क्षेत्रात असतात आणि तेच त्यांच्याकडे असते. Responsive design म्हणजे प्रत्येक अभ्यासक्रम, हँडआउट, लॅब, आणि गेम तुम्ही वापरत असलेल्या कोणत्याही उपकरणावर कार्य करते. शिकण्यासाठी किंवा सुलभ करण्यासाठी तुम्हाला लॅपटॉपची गरज नाही.

## S

### Skill (Claude AI Context)

Claude सारख्या AI सहाय्यकांच्या संदर्भात, **Skill** ही एक पूर्व-निर्मित आज्ञा आहे जी एक विशिष्ट, संरचित कार्य करते. तुम्ही एखादी आज्ञा टाइप करून (जसे की "/analyze-program") एक skill सुरू करता, आणि AI निर्धारित पायऱ्यांच्या क्रमातून जातो — प्रश्न विचारणे, डेटा मिळवणे, विश्लेषण संरचित करणे.

**याचा असा विचार करा:** skill ही एका पाककृतीसारखी आहे. एखाद्या कार्यक्रमाचे मूल्यांकन करण्यासाठी किंवा साहित्याचा आढावा घेण्यासाठी प्रत्येक वेळी सुरुवातीपासून सुरू करण्याऐवजी, तुम्ही एक skill सुरू करता जी तुम्हाला पायरीपायरीने प्रक्रियेतून नेते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** ImpactMojo विकास संशोधन कार्यांसाठी सानुकूल Skills विकसित करत आहे — कार्यक्रम मूल्यांकन, पुरावा आढावा, निर्देशक विश्लेषण, आणि बरेच काही. ज्यांना prompt engineering ची पार्श्वभूमी नाही अशा व्यावसायिकांसाठी AI साधने व्यावहारिक आणि सुलभ बनवण्यासाठी ही डिझाइन केली आहेत. उपलब्ध skills [Dataverse](dataverse-guide.md) सूचीबद्ध करते.

### South Asian Context

ImpactMojo मध्ये **भारत, बांगलादेश, नेपाळ, श्रीलंका**, आणि व्यापक दक्षिण आशियाई प्रदेशातून घेतलेली उदाहरणे, केस स्टडीज, डेटा, आणि परिस्थिती वापरण्याचा एक जाणीवपूर्वक डिझाइन निर्णय.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** विकासासाठी बहुतेक ऑनलाइन शिक्षण व्यासपीठे पूर्व आफ्रिका, लॅटिन अमेरिका, किंवा ग्लोबल नॉर्थमधील उदाहरणे वापरतात. ही मौल्यवान आहेत, पण दक्षिण आशियाई परिवेशात काम करणाऱ्या व्यावसायिकांशी ती नेहमी प्रतिध्वनित होत नाहीत — जिथे शासन रचना, सामाजिक गतिशीलता, डेटा प्रणाली, आणि कार्यक्रम पद्धती यांची स्वतःची वैशिष्ट्ये आहेत. ImpactMojo चा मजकूर या प्रदेशात काम करणाऱ्या आणि त्यांना रोज भेटणाऱ्या वास्तवाचे प्रतिबिंब असलेले साहित्य हवे असलेल्या लोकांसाठी तयार केला आहे. जेव्हा एखादा अभ्यासक्रम लसीकरण कार्यक्रमावर चर्चा करतो, तेव्हा तो भारताच्या सार्वत्रिक लसीकरण कार्यक्रमाचा संदर्भ देतो, सामान्य काल्पनिकाचा नव्हे.

### Supabase

एक ओपन-सोर्स व्यासपीठ जे वेब अनुप्रयोगांसाठी डेटाबेस, प्रमाणीकरण (लॉगिन), आणि स्टोरेज सेवा पुरवते. ही ती backend पायाभूत सुविधा आहे जी ImpactMojo चा वापरकर्ता डेटा साठवते आणि व्यवस्थापित करते.

**याचा असा विचार करा:** ImpactMojo संकेतस्थळ ही जर तुम्ही प्रवेश करता ती इमारत असेल, तर Supabase ही काउंटरमागील फाइलिंग प्रणाली आहे — ती तुमची खाते माहिती साठवते, तुम्ही कोणते अभ्यासक्रम पूर्ण केले हे लक्षात ठेवते, तुमचे बुकमार्क्स ठेवते, आणि तुमची प्रमाणपत्रे व्यवस्थापित करते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** तुम्ही कधीही Supabase सोबत थेट संवाद साधणार नाही. पण जेव्हा तुम्ही खाते तयार करता, लॉग इन करता, तुमची अभ्यासक्रम प्रगती मागोवा घेता, किंवा प्रमाणपत्र मिळवता — तेव्हा ते कार्य करवणारी गोष्ट म्हणजे Supabase. हेसुद्धा ओपन सोर्स आहे, याचा अर्थ कोणतेही मालकीहक्क-आधारित लॉक-इन नाही: गरज पडल्यास तुमचा डेटा दुसऱ्या प्रणालीत हलवता येऊ शकतो.

## W

### WCAG (Web Content Accessibility Guidelines)

World Wide Web Consortium (W3C) ने विकसित केलेल्या आंतरराष्ट्रीय मानकांचा एक संच, जो अपंगत्व असलेल्या लोकांसाठी वेब मजकूर कसा सुलभ बनवायचा हे परिभाषित करतो. WCAG रंग कॉन्ट्रास्ट (जेणेकरून कमी दृष्टी असलेल्या लोकांसाठी मजकूर वाचनीय असेल), कीबोर्ड नेव्हिगेशन (जेणेकरून माउस वापरू न शकणारे लोकही नेव्हिगेट करू शकतील), आणि प्रतिमांसाठी पर्यायी मजकूर (जेणेकरून स्क्रीन रीडर अंध वापरकर्त्यांना प्रतिमांचे वर्णन करू शकतील) यांसारख्या गोष्टी व्यापते.

**हे तुमच्या कामासाठी का महत्त्वाचे आहे:** आपले अभ्यासक्रम, हँडआउट्स, आणि साधने प्रत्येकासाठी वापरण्यायोग्य आहेत हे सुनिश्चित करण्यासाठी ImpactMojo WCAG मार्गदर्शक तत्त्वांचे पालन करते. जर तुम्ही तुमचे स्वतःचे डिजिटल साहित्य तयार करत असाल — संकेतस्थळे, PDF, सादरीकरणे — तर WCAG हे ते मानक आहे ज्याचे लक्ष्य ठेवावे. ते तीन स्तरांमध्ये संघटित आहे: A (किमान), AA (शिफारस केलेले), आणि AAA (आदर्श). बहुतेक संस्था AA चे लक्ष्य ठेवतात.
