# Games मार्गदर्शक

## ImpactMojo Games म्हणजे काय?

ImpactMojo **इंटरॅक्टिव्ह games** देते जे धोरणात्मक निर्णय-प्रक्रिया आणि अनुकरणाद्वारे विकास-संबंधित संकल्पना शिकवतात. प्रत्येक खेळ खेळण्यास १०–२० मिनिटे लागतात आणि एक विशिष्ट संकल्पना समाविष्ट करतो — खेळ सिद्धांत आणि बाजार अपयशांपासून ते हवामान कृती, लैंगिक समता, सार्वजनिक आरोग्य आणि डिजिटल नैतिकतेपर्यंत.

हे क्विझ किंवा फ्लॅशकार्ड नाहीत. ही इंटरॅक्टिव्ह अनुकरणे आहेत जिथे तुमच्या निर्णयांचे परिणाम होतात, आणि संकल्पना व्याख्यानाऐवजी खेळाद्वारे स्पष्ट होतात.

सर्व games **मोफत, ब्राउझर-आधारित आहेत आणि कोणत्याही लॉगिनची आवश्यकता नाही**. ती impactmojo.in वर `/Games/` मध्ये स्व-होस्ट केलेली आहेत.

### MiroFish AI Agents

अर्थशास्त्राच्या games मध्ये **MiroFish AI agents** असतात — AI-चालित प्रतिस्पर्धी ज्यांच्याकडे वेगळ्या दक्षिण आशियाई ओळखी, पार्श्वकथा आणि धोरणात्मक व्यक्तिमत्त्वे असतात. प्रत्येक agent कडे त्यांचे निर्णय आकाराला आणणारी अंशांकित व्यक्तिमत्त्व वैशिष्ट्ये (सहकार्य पूर्वग्रह, जोखीम सहनशीलता, स्मृती भार) असतात. तुम्ही एखाद्या यादृच्छिक संख्या जनरेटरविरुद्ध खेळत नाही — तुम्ही व्यावहारिक NGO संचालक मीरासोबत वाटाघाटी करत आहात, आदर्शवादी संशोधक अर्जुनसोबत वादविवाद करत आहात, किंवा हुशार खरेदी अधिकारी नंदिनीविरुद्ध स्पर्धा करत आहात.

ही AI प्रणाली एका Supabase Edge Function द्वारे **बहु-प्रदाता LLM फॉलबॅक साखळी** (DeepSeek → Groq → Gemini → Together → OpenAI) वापरते. जेव्हा LLM प्रदाते उपलब्ध नसतात, तेव्हा एक स्थानिक व्यक्तिमत्त्व इंजिन भारित अनुमानांचा वापर करून निर्णय तयार करते — त्यामुळे games नेहमी काम करतात, ऑफलाइनही.

AI प्रणालीच्या तांत्रिक तपशिलांसाठी [Game Agents documentation](game-agents.md) पाहा.

## शिक्षक Games चा वापर कसा करू शकतात

### कार्यशाळेच्या प्रारंभकर्त्या म्हणून

एखादी संकल्पना अनुभवात्मकरीत्या सादर करण्यासाठी सत्राच्या सुरुवातीला एक खेळ खेळा. तुम्ही सिद्धांत समजावण्याच्या *आधी* सहभागी कल्पनेशी जोडले जातात — हे कुतूहल निर्माण करते आणि त्यांना चर्चेसाठी एक सामायिक संदर्भबिंदू देते.

**उदाहरण प्रवाह:**
1. Public Good Game खेळा (१० मिनिटे)
2. आढावा: "काय घडले? योगदान का घसरले?" (१० मिनिटे)
3. पब्लिक गुड्स आणि फ्री-रायडिंगची औपचारिक संकल्पना सादर करा (१५ मिनिटे)
4. त्यांच्या कार्यक्रमांमधील वास्तविक-जगातील उपयोगांवर चर्चा करा (१५ मिनिटे)

### वर्ग क्रियाकलाप म्हणून

गट खेळासाठी स्क्रीनवर प्रक्षेपित केल्यावर games चांगले काम करतात. वर्गाला एकत्रितपणे निर्णयांवर मतदान करायला लावा, किंवा संघांमध्ये विभागा आणि परिणामांची तुलना करा.

**चांगल्या जोड्या:**
- Public Good Game + Commons Crisis = सामूहिक कृतीचा व्यापक दृष्टिकोन
- Information Asymmetry + Externality = बाजार अपयशे एकत्र समजून घेणे
- Prisoners' Dilemma + Cooperation Paradox = धोरणात्मक विचारात खोल शोध

### स्व-अध्ययन असाइनमेंट म्हणून

एखाद्या कार्यशाळेपूर्वी पूर्व-कार्य म्हणून २–३ games नेमून द्या. सहभागींना एक-परिच्छेद चिंतन लिहायला सांगा: "तुम्हाला काय आश्चर्यचकित केले? ही संकल्पना तुमच्या कामात कशी दिसते?"

### आढावा चर्चांसाठी

कोणत्याही खेळानंतर, हे प्रश्न चांगले काम करतात:
- तुम्ही कोणती रणनीती वापरली? ती फेरी-दर-फेरी बदलली का?
- परिणामाबद्दल तुम्हाला काय आश्चर्यचकित केले?
- तुमच्या विकासकार्यात ही गतिशीलता कुठे दिसते?
- कोणत्या यंत्रणा परिणाम बदलू शकतात?

## सुरुवात कशी करावी

1. **Games विभागात जा** [impactmojo.in](https://www.impactmojo.in) वर — Games शोकेसपर्यंत स्क्रोल करा किंवा कॅटलॉगमध्ये शोधा
2. **Public Good Game किंवा Prisoners' Dilemma पासून सुरुवात करा** — हे सर्वात सहज प्रवेशबिंदू आहेत
3. **प्रत्येक खेळ प्रथम स्वतः खेळा** एखाद्या कार्यशाळेत वापरण्यापूर्वी, जेणेकरून तुम्ही सहभागींच्या प्रश्नांचा अंदाज घेऊ शकता
4. **लॉगिन किंवा डाउनलोडची आवश्यकता नाही** — games डेस्कटॉप किंवा मोबाइलवर कोणत्याही आधुनिक ब्राउझरमध्ये चालतात

## टिपा

- **Games प्रौढांसाठी रचली आहेत, मुलांसाठी नव्हे.** मांडणी, भाषा आणि गुंतागुंत विकास क्षेत्रातील व्यावसायिक आणि विद्यापीठ विद्यार्थ्यांच्या पातळीवर निश्चित केली आहे.
- **आढावा हीच जागा आहे जिथे शिकणे घडते.** खेळ स्वतः अनुभव निर्माण करतो; त्यानंतरची चर्चा समज निर्माण करते. आढाव्यासाठी नेहमी वेळ राखून ठेवा.
- **अनेक फेऱ्या खेळा.** सहभागी त्यांच्या रणनीती समायोजित करत असल्याने बहुतेक games दुसऱ्या आणि तिसऱ्या खेळात अधिक खोल गतिशीलता प्रकट करतात.
- **वास्तविक कार्यक्रमांशी जोडा.** Commons Crisis Game खेळल्यानंतर विचारा: "तुमच्या WASH कार्यक्रमात सामायिक संपत्तीची कोंडी कुठे दिसते?" ही हस्तांतरण पायरी आवश्यक आहे.
