# BCT Repository मार्गदर्शक

## BCT Repository म्हणजे काय?

ImpactMojo BCT Repository हा **200+ वर्तन बदल तंत्रांचा (Behaviour Change Techniques) मोफत, शोधण्यायोग्य संग्रह** आहे — जो आंतरराष्ट्रीय स्तरावर मान्यताप्राप्त BCT Taxonomy v1 (93 मुख्य तंत्रे) ला दक्षिण आशियाई विकास सरावासाठी संदर्भित केलेल्या 100+ अतिरिक्त तंत्रांसह एकत्र करतो.

तुम्ही आरोग्य कार्यक्रम, WASH हस्तक्षेप, शिक्षण मोहिमा, किंवा लोकांचे वर्तन बदलण्याचे उद्दिष्ट असलेले कोणतेही कार्य आखत असाल, तर हा repository तुम्हाला पुराव्यांनी समर्थित योग्य तंत्रे शोधण्यास मदत करतो — आणि त्यांचे प्रमाणित IDs तुमच्या प्रस्तावांमध्ये आणि logframes मध्ये वापरण्यास मदत करतो.

---

## वर्तन बदल तंत्रे म्हणजे काय?

एक **वर्तन बदल तंत्र (Behaviour Change Technique, BCT)** हा वर्तन बदलण्यासाठी आखलेल्या हस्तक्षेपाचा एक विशिष्ट, पुनरुत्पादनीय घटक आहे. "आम्ही जागरूकता वाढवू" असे अस्पष्टपणे म्हणण्याऐवजी, एक BCT तुम्हाला व्याख्या, पुरावा आधार आणि taxonomy ID सह एक नेमके तंत्र देते.

**उदाहरण:** BCT 1.1 "ध्येय निर्धारण (वर्तन)" — व्यक्ती एक विशिष्ट वर्तनात्मक ध्येय ठरवते (उदा., "मी प्रत्येक जेवणापूर्वी हात धुईन"). हे असे तंत्र आहे ज्याला तुम्ही नाव देऊ शकता, मोजू शकता आणि पुनरुत्पादित करू शकता.

तुमच्या कार्यक्रम आखणीत प्रमाणित BCTs वापरल्याने हस्तक्षेप अधिक नेमके, मूल्यांकनयोग्य आणि अभ्यासांमध्ये तुलनात्मक बनतात.

## Repository कशी आयोजित आहे

### श्रेणीनुसार

तंत्रे क्षेत्रानुसार आयोजित आहेत जेणेकरून तुम्ही तुमच्या क्षेत्रासाठी संबंधित गोष्टी शोधू शकता:

| श्रेणी | केंद्रबिंदू |
|----------|-------|
| Health | पोषण, माता आरोग्य, रोग प्रतिबंध, WASH वर्तन |
| Education | शिकण्याच्या सवयी, शाळा उपस्थिती, शिक्षक पद्धती |
| Livelihoods | आर्थिक वर्तन, कृषी पद्धती, बाजार सहभाग |
| WASH | हात धुणे, स्वच्छता अंगीकारणे, पाणी प्रक्रिया |
| Gender | लिंग-समतावादी वर्तन, GBV प्रतिबंध, महिला एजन्सी |
| Governance | नागरी सहभाग, पारदर्शकता, उत्तरदायित्व वर्तन |

### पुरावा स्तरानुसार

प्रत्येक तंत्राला एका पुरावा रेटिंगसह टॅग केले आहे:

- **Strong** — अनेक कठोर अभ्यासांनी (RCTs, पद्धतशीर पुनरावलोकने) समर्थित
- **Moderate** — निरीक्षणात्मक अभ्यास किंवा मर्यादित प्रयोगात्मक पुराव्यांनी समर्थित
- **Emerging** — आशादायक परंतु मर्यादित औपचारिक मूल्यांकनासह

हस्तक्षेप आखताना, Strong पुरावा असलेल्या तंत्रांना प्राधान्य द्या. जिथे कोणतेही Strong पर्याय अस्तित्वात नाहीत तिथे Emerging तंत्रे वापरा आणि त्यांचे मूल्यांकन करण्याची योजना करा.

## प्रमुख वैशिष्ट्ये

### शोध आणि फिल्टरिंग

repository मध्ये fuzzy matching सह पूर्ण-मजकूर शोध आहे — एक कीवर्ड, तंत्राचे नाव, क्षेत्र किंवा कार्यक्रम प्रकार टाइप करा आणि क्रमवारी लावलेले निकाल मिळवा. तुम्ही यांनुसारही फिल्टर करू शकता:

- **श्रेणी** — Health, Education, WASH, Gender, Livelihoods, Governance
- **पुरावा स्तर** — Strong, Moderate, Emerging
- **कीवर्ड** — तंत्राच्या नावात किंवा व्याख्येतील कोणतीही संज्ञा

### तंत्र कार्डे

प्रत्येक तंत्र एका कार्डाच्या स्वरूपात प्रदर्शित होते जे दाखवते:

- **Taxonomy ID** (उदा., BCT 1.1) — प्रमाणित ओळखकर्ता
- **नाव** — तंत्राला काय म्हणतात
- **व्याख्या** — तंत्रात नेमके काय समाविष्ट आहे
- **पुरावा स्तर** — रंग-कोडेड badge
- **श्रेणी टॅग** — हे कोणत्या क्षेत्रांना लागू होते

संबंधित तंत्रे आणि cross-links सह विस्तारित दृश्यासाठी कोणत्याही कार्डावर क्लिक करा.

### बुकमार्क आणि निर्यात

- नंतरच्या संदर्भासाठी वैयक्तिक संग्रहात **तंत्रे जतन करा**
- कार्यशाळा handouts साठी **वैयक्तिक कार्डे छापा**
- पर्यायांमधून निवडण्यासाठी **तंत्रांची तुलना करा** शेजारी-शेजारी
- कार्यक्रम दस्तऐवजांमध्ये समावेशासाठी **CSV मध्ये निर्यात करा**

## शिक्षक BCT Repository कशी वापरू शकतात

### अभ्यासक्रम आखणीत

हस्तक्षेप आखणी शिकवताना repository चा संदर्भ म्हणून वापर करा. विद्यार्थ्यांकडून करवून घ्या:

1. त्यांना बदलू इच्छित असलेले वर्तन ओळखा
2. संबंधित तंत्रांसाठी repository शोधा
3. Strong विरुद्ध Emerging पुरावा पर्यायांची तुलना करा
4. पूरक तंत्रांचे एक संयोजन निवडा
5. प्रमाणित BCT IDs वापरून त्यांचा हस्तक्षेप लिहा

### कार्यशाळांमध्ये

- **पूर्व-वाचन:** सत्रापूर्वी सहभागींना एक विशिष्ट श्रेणी ब्राउझ करण्यासाठी नियुक्त करा
- **उपक्रम:** संघांना एक केस स्टडी द्या आणि त्यांच्या हस्तक्षेप आखणीसाठी 3–5 BCTs निवडण्यास सांगा
- **चर्चा:** संघ निवडींची तुलना करा — वेगवेगळ्या गटांनी वेगवेगळी तंत्रे का निवडली?

### प्रस्ताव लेखनात

सहभागींना प्रस्तावांमध्ये BCT taxonomy IDs चा संदर्भ देणे शिकवा. निधीदाते वाढत्या प्रमाणात पुरावा-आधारित हस्तक्षेप आखणीची अपेक्षा करतात, आणि विशिष्ट BCTs चा हवाला देणे (उदा., "आम्ही BCT 1.1 ध्येय निर्धारण आणि BCT 2.2 वर्तनावरील अभिप्राय वापरू") काटेकोरपणा दर्शवते.

### Theory of Change शी जोडणे

BCTs थेट Theory of Change च्या "क्रियाकलाप" आणि "यंत्रणा" स्तरांशी जुळतात. विशिष्ट तंत्रे विशिष्ट परिणाम कसे चालवतात हे दाखवण्यासाठी repository चा Theory of Change Lab सोबत वापर करा.

1. [impactmojo.in/bct-repository.html](https://www.impactmojo.in/bct-repository.html) वर **BCT Repository ला भेट द्या**

5. **उपयुक्त तंत्रे बुकमार्क करा** — तुमच्या कार्यक्रम क्षेत्रासाठी एक संग्रह तयार करा

## टिपा

- **पूरक तंत्रे एकत्र करा.** प्रभावी वर्तन बदल हस्तक्षेप सामान्यतः एकत्रितपणे 3–7 BCTs वापरतात, फक्त एकच नाही.
- **तुमच्या संदर्भात पुरावा तपासा.** जागतिक स्तरावर Strong पुरावा असलेल्या तंत्राला दक्षिण आशियाई परिस्थितीत मर्यादित पुरावा असू शकतो — जिथे संबंधित असेल तिथे repository हे चिन्हांकित करते.
- **taxonomy IDs सातत्याने वापरा.** प्रस्ताव, M&E योजना, किंवा संशोधन पेपर लिहिताना, स्पष्टता आणि तुलनात्मकतेसाठी नेहमी नावासह BCT ID समाविष्ट करा.
- **परिचितापासून सुरुवात करा.** तुम्ही आधीच "जागरूकता मोहिमा" करत असाल, तर त्या मोहिमा प्रत्यक्षात कोणत्या BCTs वापरतात ते शोधा — तुम्हाला आढळेल की तुम्ही आधीच BCT 5.1 "आरोग्य परिणामांबद्दल माहिती" सारखी तंत्रे नाव न देता वापरत आहात.
