# எழுத்துரு வடிவமைப்பு

ImpactMojo அனைத்து 242+ பக்கங்களிலும் தரப்படுத்தப்பட்ட மூன்று-எழுத்துரு அமைப்பைப் பயன்படுத்துகிறது:

| பங்கு | எழுத்துரு | எடைகள் | மாற்றுத் தேர்வு |
|------|------|---------|----------|
| **தலைப்புகள்** | Inter | 400, 500, 600, 700, 800 | sans-serif |
| **உள்ளடக்க உரை** | Amaranth | 400, 700 | sans-serif |
| **குறியீடு / monospace** | JetBrains Mono | 400 | monospace |
| **பன்மொழி** | Noto Sans (தேவநாகரி, பெங்காலி, தமிழ், தெலுங்கு) | 400, 700 | sans-serif |

## Google Fonts ஏற்றுதல்

அனைத்து பக்கங்களும் ஒரே Google Fonts URL வழியாக எழுத்துருக்களை ஏற்றுகின்றன:

```html
<link href="https://fonts.googleapis.com/css2?family=Amaranth:wght@400;700&family=Inter:wght@400;500;600;700;800&family=JetBrains+Mono&family=Noto+Sans:wght@400;700&display=swap" rel="stylesheet">
```

## வடிவமைப்பு டோக்கன்கள்

### எழுத்துரு குடும்பங்கள்

```css
--font-heading: 'Inter', sans-serif;
--font-body: 'Amaranth', sans-serif;
--font-mono: 'JetBrains Mono', monospace;
```

### எழுத்துரு அளவுகள்

| டோக்கன் | அளவு | பயன்பாடு |
|-------|------|-------|
| `--text-xs` | 0.75rem | லேபிள்கள், தலைப்புரைகள் |
| `--text-sm` | 0.875rem | இரண்டாம் நிலை உரை, மெட்டாடேட்டா |
| `--text-base` | 1rem | உள்ளடக்க உரை |
| `--text-lg` | 1.125rem | முன்னுரைப் பத்திகள் |
| `--text-xl` | 1.25rem | பிரிவுத் தலைப்புகள் (h3) |
| `--text-2xl` | 1.5rem | பக்கத் தலைப்புகள் (h2) |
| `--text-3xl` | 1.875rem | முதன்மைத் தலைப்புகள் (h1) |

### எழுத்துரு எடைகள்

| டோக்கன் | எடை | பயன்பாடு |
|-------|--------|-------|
| `--font-normal` | 400 | உள்ளடக்க உரை |
| `--font-medium` | 500 | வழிசெலுத்தல், பொத்தான்கள் |
| `--font-semibold` | 600 | துணைத் தலைப்புகள் |
| `--font-bold` | 700 | தலைப்புகள், அழுத்தம் |
| `--font-extrabold` | 800 | முதன்மை உரை |

## குறியாக்கம்

அனைத்து HTML கோப்புகளும் UTF-8 குறியாக்கத்தைப் பயன்படுத்துகின்றன:

```html
<meta charset="UTF-8">
```

இது பின்வருவனவற்றின் சரியான ரெண்டரிங்கை உறுதி செய்கிறது:
- ஹிந்தி (हिन्दी), பெங்காலி (বাংলা), தமிழ் (தமிழ்), தெலுங்கு (తెలుగు)
- கல்வி உள்ளடக்கத்தில் சிறப்பு எழுத்துகள் (em-dashes, smart quotes, முதலியன)
