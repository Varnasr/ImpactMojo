## கற்றல் பாதைகள்

உள்ளடக்கம் 6 பாதைகளாக ஒழுங்கமைக்கப்பட்டுள்ளது:

1. **MEL & Research** — கண்காணிப்பு, மதிப்பீடு, தரம்சார்/அளவுசார் முறைகள்
2. **Economics & Policy** — வளர்ச்சிப் பொருளாதாரம், அரசியல் பொருளாதாரம், fundraising
3. **Gender & Equity** — பாலின ஆய்வுகள், WEE, care economy, data feminism
4. **Governance & Society** — அரசியலமைப்பு, காலனியமயமாக்கல் நீக்கம், சமூக வளர்ச்சி
5. **Health & Wellbeing** — பொது சுகாதாரம், காலநிலை, SEL, வாழ்வாதாரங்கள்
6. **Communication & Data** — தரவு எழுத்தறிவு, visual ethnography, BCC, advocacy

## Flagship பாடநெறி கட்டமைப்பு

ஒவ்வொரு flagship பாடநெறியும் ஒரு நிலையான கட்டமைப்பைப் பின்பற்றுகிறது:

- **13 தொகுதிகள்** (தோராயமாக)
- 50–65 முக்கியச் சொற்களின் **Lexicon**
- **தென்னாசியச் சூழல்** — இந்தியா, பங்களாதேஷ், நேபாளம், இலங்கை இலிருந்து எடுத்துக்காட்டுகள்
- **வழக்காய்வுகள்** — உண்மையான வளர்ச்சித் திட்டங்கள் மற்றும் மதிப்பீடுகள்
- **சிந்தனைத் தூண்டுதல்கள்** — பயிற்சியாளர்கள் தங்கள் வேலையுடன் இணைக்க
- **மேலும் படிப்பு** — DevDiscourses இலிருந்து தேர்ந்தெடுக்கப்பட்டது

## Interactive Labs

லேப்கள் HTML/JS workbench-கள், அவை பயிற்சியாளர்களை கருத்துக்களைப் பயன்படுத்த அனுமதிக்கின்றன. ஒவ்வொரு லேப்பும்:

- ஒரு வழிநடத்தப்பட்ட பணிப்பாய்வு (படிப்படியாக) கொண்டுள்ளது
- ஒரு வெளியீட்டை உருவாக்குகிறது (கட்டமைப்பு, திட்டம், பகுப்பாய்வு)
- முடிவுகளை ஏற்றுமதி செய்யலாம் (premium பதிப்புகளில் PDF/PNG)
- சர்வர் தேவையில்லை — முழுவதும் உலாவியில் இயங்குகிறது

## Learning Games

விளையாட்டுகள் ஒற்றை HTML பக்கங்களாக கட்டப்பட்ட பொருளாதார உருவகப்படுத்துதல்கள்:

- **தன்னிறைவு** — ஒவ்வொரு விளையாட்டும் ஒரு HTML கோப்பு
- **தரவு-உந்துதல்** — முடிந்தவரை உண்மையான பொருளாதார அளவுருக்கள்
- **debrief செய்யக்கூடியது** — வகுப்பறை அல்லது பட்டறை பயன்பாட்டிற்காக வடிவமைக்கப்பட்டது
- **மொபைல்-நட்பு** — பதிலளிக்கும் layout-கள்

## புதிய உள்ளடக்கத்தைச் சேர்த்தல்

### புதிய foundational பாடநெறியைச் சேர்த்தல்

1. தற்போதைய பாடநெறி வடிவத்தைப் பின்பற்றி ஒரு புதிய HTML கோப்பை உருவாக்கவும்
2. பாடநெறியை `catalog.html` இல் உள்ள பட்டியலில் சேர்க்கவும்
3. அதை முதன்மைத் தளத்தின் பாடநெறிப் பட்டியலில் `index.html` இல் சேர்க்கவும்
4. README உள்ளடக்க சரக்குப்பட்டியலைப் புதுப்பிக்கவும்

### புதிய விளையாட்டைச் சேர்த்தல்

1. விளையாட்டு தர்க்கத்துடன் ஒரு ஒற்றை HTML கோப்பை உருவாக்கவும்
2. அதை பொருத்தமான கோப்பகத்தில் அல்லது தனி Netlify தளமாக ஹோஸ்ட் செய்யவும்
3. அதை `index.html` மற்றும் `catalog.html` இல் உள்ள விளையாட்டுப் பிரிவில் சேர்க்கவும்

### Handouts சேர்த்தல்

Handouts ரெப்போவிலிருந்து இயங்குநிலையில் ஏற்றப்படுகின்றன. Handouts தொகுப்பில் HTML கோப்புகளைச் சேர்க்கவும், அவை தானாகவே தோன்றும்.

## பாணி வழிகாட்டி

- **தொனி:** அணுகக்கூடியது ஆனால் கடுமையானது. 2–3 ஆண்டுகள் அனுபவமுள்ள ஒரு பயிற்சியாளருக்காக எழுதுங்கள்.
- **எடுத்துக்காட்டுகள்:** தென்னாசியச் சூழலை விரும்பவும் (இந்தியா, பங்களாதேஷ், நேபாளம், இலங்கை).
- **பரிபாஷை:** முதல் பயன்பாட்டில் சொற்களை வரையறுக்கவும். அவை துறை-தரநிலையாக இருந்தால் அவற்றை ImpactLex இல் சேர்க்கவும்.
- **பங்களிப்பு:** மூலங்களை மேற்கோள் காட்டவும். முடிந்தவரை DevDiscourses உடன் இணைக்கவும்.
- **அணுகல்தன்மை:** சொற்பொருள் HTML, படங்களுக்கு alt text, மற்றும் போதுமான வண்ண மாறுபாட்டைப் பயன்படுத்தவும்.

## ஒரு Deep Dive ஐ எவ்வாறு எழுதுவது

Deep Dives தேர்ந்தெடுக்கப்பட்ட விளக்கப் படிப்புப் பட்டியல்கள். ஒவ்வொரு பட்டியலும் ஒரு பெயரிடப்பட்ட தொகுப்பாளரின் குரலுடன் கூடிய ஒரு தலையங்கப் படைப்பாகும், ஒரு நடுநிலை நூற்பட்டியல் அல்ல — ஒரு தனித்த குறிப்புப் பக்கத்தை விட ஒரு நீள்-வடிவ கட்டுரை-பாடத்திட்டத்திற்கு நெருக்கமானது.

### ஒரு Deep Dive ன் அமைப்பு

1. **Hero** — தலைப்பு, ஒரு-வரி குறிக்கோள், தலைப்பு chip, படிப்புகளின் எண்ணிக்கை.
2. **Curator card** — பெயர், பங்கு, 2–3 வாக்கிய சுயவிவரம். `Editor's Pick` (உள்ளக) அல்லது `Invited Curator` என குறிக்கவும்.
3. **Editor's Note** — தொகுப்பாளரின் குரலில் 2–4 பத்தி கட்டமைப்புக் கட்டுரை. இதுவே சாரம்; பட்டியல் ரசீது மட்டுமே.
4. **3–6 கருப்பொருள் பிரிவுகள்** — எ.கா. "Foundations", "Recent Debates", "Voices from the Field". தட்டையான பட்டியலை உருவாக்க வேண்டாம்.
5. **படிப்பு உருப்படிகள்** — ஒவ்வொன்றிற்கும்: ஒரு வகை badge (📘 Book / 📄 Paper / 🎙 Podcast / 🎬 Film / 📊 Dataset / 📰 Article / 🌐 Web), வெளிச்செல்லும் இணைப்புடன் ஒரு முழு மேற்கோள், மற்றும் படைப்பு ஏன் முக்கியம் மற்றும் அது பாடத்திட்டத்தில் எவ்வாறு பொருந்துகிறது என்பதைக் கூறும் 2–4 வாக்கிய விளக்கம்.
6. **தொடர்புடைய ImpactMojo உள்ளடக்கம்** — 2–4 பாடநெறிகள், லேப்கள், விளையாட்டுகள் அல்லது புத்தக துணைகளை குறுக்கு-இணைக்கவும்.
7. **பரிந்துரைக்கப்பட்ட மேற்கோள்** — APA-பாணி மேற்கோள் தொகுதி.
8. **Contribute CTA** — pitch படிவத்திற்கான இணைப்பு.

### உருவாக்க / புதுப்பிக்க வேண்டிய கோப்புகள்

ஒரு புதிய Deep Dive ஐச் சேர்க்க:

1. `/DeepDives/_template.html` → `/DeepDives/{slug}.html` நகலெடுக்கவும். தலைப்பு, குறிக்கோள், தலைப்பு, தொகுப்பாளர், editor's note, பிரிவுகள், படிப்புகளை நிரப்பவும்.
2. `/data/deep-dives.json` இல் ஒரு உள்ளீட்டைச் சேர்க்கவும் (id, title, tagline, topic, url, curator, sections, tags, reading_count, published).
3. `/data/search-index.json` இல் `"type": "deep-dive"` மற்றும் `"category": "Deep Dives"` உடன் ஒரு உள்ளீட்டைச் சேர்க்கவும்.
4. `/sitemap.xml` இல் ஒரு `<url>` உள்ளீட்டைச் சேர்க்கவும்.
5. `catalog.html` இன் `allContent` array இல் ஒரு card ஐச் சேர்க்கவும் (`type: 'deep-dive'`, ஒரு பாதையைத் தேர்ந்தெடுக்கவும்).
6. (விருப்பத்தேர்வு) flagship-தரம் கொண்டதாக இருந்தால் `/index.html` இல் உள்ள Deep Dives பிரிவைத் திருத்தி அதை முகப்புப் பக்கத்தில் இடம்பெறச் செய்யவும்.
7. எல்லா இடங்களிலும் எண்ணிக்கை உரையைப் புதுப்பிக்கவும் — `(5 Deep Dives|5 readings)` ஐ grep செய்து எண்ணை அதிகரிக்கவும்.

### தலையங்க வழிகாட்டுதல்கள்

- **நடுநிலைக்கு மேல் தொகுப்பாளர் குரல்.** ஒரு பார்வையற்ற பட்டியல் வெறும் நூற்பட்டியல் மட்டுமே. வாசகரின் கைகளில் நீங்கள் என்ன திணிக்க விரும்புகிறீர்கள், ஏன் என்று சொல்லுங்கள்.
- **கலப்பு ஊடகம் ஊக்குவிக்கப்படுகிறது.** ஒரு நல்ல Deep Dive ஆகாஷ்ய மையத்துடன் குறைந்தது ஒரு பாட்காஸ்ட், ஒரு dataset மற்றும் ஒரு பயிற்சியாளர்-நோக்கிய மூலத்தைக் கொண்டுள்ளது.
