# BCT Repository வழிகாட்டி

## BCT Repository என்றால் என்ன?

ImpactMojo BCT Repository என்பது **200+ நடத்தை மாற்ற நுட்பங்களின் (Behaviour Change Techniques) இலவச, தேடக்கூடிய தொகுப்பு** ஆகும் — இது சர்வதேச அளவில் அங்கீகரிக்கப்பட்ட BCT Taxonomy v1 (93 முக்கிய நுட்பங்கள்) உடன், தென் ஆசிய வளர்ச்சிப் பயிற்சிக்கு ஏற்ப வடிவமைக்கப்பட்ட 100+ கூடுதல் நுட்பங்களை இணைக்கிறது.

நீங்கள் சுகாதாரத் திட்டங்கள், WASH தலையீடுகள், கல்வி பிரச்சாரங்கள், அல்லது மக்களின் நடத்தையை மாற்றுவதை நோக்கமாகக் கொண்ட எந்தவொரு பணியையும் வடிவமைத்தால், இந்த repository சான்றுகளால் ஆதரிக்கப்படும் சரியான நுட்பங்களைக் கண்டுபிடிக்க உதவுகிறது — மேலும் அவற்றின் தரப்படுத்தப்பட்ட IDs-ஐ உங்கள் முன்மொழிவுகளிலும் logframes-லும் பயன்படுத்த உதவுகிறது.

---

## நடத்தை மாற்ற நுட்பங்கள் என்றால் என்ன?

ஒரு **நடத்தை மாற்ற நுட்பம் (Behaviour Change Technique, BCT)** என்பது நடத்தையை மாற்றுவதற்காக வடிவமைக்கப்பட்ட ஒரு தலையீட்டின் குறிப்பிட்ட, மீண்டும் செயல்படுத்தக்கூடிய ஒரு கூறு ஆகும். "நாங்கள் விழிப்புணர்வை அதிகரிப்போம்" என்று தெளிவற்ற முறையில் சொல்வதற்குப் பதிலாக, ஒரு BCT உங்களுக்கு ஒரு வரையறை, சான்று அடிப்படை மற்றும் taxonomy ID கொண்ட துல்லியமான நுட்பத்தை வழங்குகிறது.

**எடுத்துக்காட்டு:** BCT 1.1 "இலக்கு நிர்ணயம் (நடத்தை)" — நபர் ஒரு குறிப்பிட்ட நடத்தை இலக்கை நிர்ணயிக்கிறார் (எ.கா., "நான் ஒவ்வொரு உணவுக்கு முன்பும் கைகளைக் கழுவுவேன்"). இது நீங்கள் பெயரிடவும், அளவிடவும், மீண்டும் செயல்படுத்தவும் கூடிய ஒரு நுட்பம்.

உங்கள் திட்ட வடிவமைப்பில் தரப்படுத்தப்பட்ட BCTs-ஐப் பயன்படுத்துவது தலையீடுகளை மிகவும் துல்லியமாகவும், மதிப்பிடக்கூடியதாகவும், ஆய்வுகளுக்கு இடையே ஒப்பிடக்கூடியதாகவும் ஆக்குகிறது.

## Repository எவ்வாறு ஒழுங்கமைக்கப்பட்டுள்ளது

### வகை வாரியாக

உங்கள் துறைக்குப் பொருத்தமானதைக் கண்டுபிடிக்க, நுட்பங்கள் களத்தின் அடிப்படையில் ஒழுங்கமைக்கப்பட்டுள்ளன:

| வகை | கவனம் |
|----------|-------|
| Health | ஊட்டச்சத்து, தாய்வழி சுகாதாரம், நோய் தடுப்பு, WASH நடத்தைகள் |
| Education | கற்றல் பழக்கங்கள், பள்ளி வருகை, ஆசிரியர் நடைமுறைகள் |
| Livelihoods | நிதி நடத்தைகள், விவசாய நடைமுறைகள், சந்தைப் பங்கேற்பு |
| WASH | கைகழுவுதல், சுகாதாரம் ஏற்றல், நீர் சுத்திகரிப்பு |
| Gender | பாலினச் சமத்துவ நடத்தைகள், GBV தடுப்பு, பெண்களின் முகமை |
| Governance | குடிமை பங்கேற்பு, வெளிப்படைத்தன்மை, பொறுப்புக்கூறல் நடத்தைகள் |

### சான்று நிலை வாரியாக

ஒவ்வொரு நுட்பமும் ஒரு சான்று மதிப்பீட்டுடன் குறியிடப்பட்டுள்ளது:

- **Strong** — பல கடுமையான ஆய்வுகளால் (RCTs, முறையான மதிப்பாய்வுகள்) ஆதரிக்கப்படுகிறது
- **Moderate** — அவதானிப்பு ஆய்வுகள் அல்லது வரம்புக்குட்பட்ட சோதனைச் சான்றுகளால் ஆதரிக்கப்படுகிறது
- **Emerging** — நம்பிக்கைக்குரியது ஆனால் வரம்புக்குட்பட்ட முறையான மதிப்பீட்டுடன்

தலையீடுகளை வடிவமைக்கும்போது, Strong சான்று கொண்ட நுட்பங்களுக்கு முன்னுரிமை அளியுங்கள். Strong மாற்றுகள் எதுவும் இல்லாத இடத்தில் Emerging நுட்பங்களைப் பயன்படுத்தி, அவற்றை மதிப்பிடத் திட்டமிடுங்கள்.

## முக்கிய அம்சங்கள்

### தேடல் மற்றும் வடிகட்டுதல்

repository-இல் fuzzy matching உடன் முழு-உரைத் தேடல் உள்ளது — ஒரு முக்கிய சொல், நுட்பப் பெயர், துறை அல்லது திட்ட வகையைத் தட்டச்சு செய்து தரவரிசைப்படுத்தப்பட்ட முடிவுகளைப் பெறுங்கள். இவற்றின் மூலமும் வடிகட்டலாம்:

- **வகை** — Health, Education, WASH, Gender, Livelihoods, Governance
- **சான்று நிலை** — Strong, Moderate, Emerging
- **முக்கிய சொல்** — நுட்பப் பெயரிலோ வரையறையிலோ உள்ள எந்தவொரு சொல்

### நுட்ப அட்டைகள்

ஒவ்வொரு நுட்பமும் ஒரு அட்டையாகக் காட்டப்படுகிறது, அது காட்டுவது:

- **Taxonomy ID** (எ.கா., BCT 1.1) — தரப்படுத்தப்பட்ட அடையாளங்காட்டி
- **பெயர்** — நுட்பம் எவ்வாறு அழைக்கப்படுகிறது
- **வரையறை** — நுட்பத்தில் சரியாக என்ன அடங்கியுள்ளது
- **சான்று நிலை** — வண்ணக்-குறியிடப்பட்ட badge
- **வகை குறிச்சொற்கள்** — இது எந்தத் துறைகளுக்குப் பொருந்தும்

தொடர்புடைய நுட்பங்கள் மற்றும் cross-links கொண்ட விரிவாக்கப்பட்ட காட்சிக்கு எந்த அட்டையையும் கிளிக் செய்யுங்கள்.

### புத்தகக்குறிகள் மற்றும் ஏற்றுமதி

- பின்னர் குறிப்பிட ஒரு தனிப்பட்ட தொகுப்பில் **நுட்பங்களைச் சேமியுங்கள்**
- பட்டறை handouts-க்கு **தனிப்பட்ட அட்டைகளை அச்சிடுங்கள்**
- மாற்றுகளுக்கு இடையே தேர்வு செய்ய **நுட்பங்களை** அருகருகே **ஒப்பிடுங்கள்**
- திட்ட ஆவணங்களில் சேர்க்க **CSV-க்கு ஏற்றுமதி செய்யுங்கள்**

## கல்வியாளர்கள் BCT Repository-ஐ எவ்வாறு பயன்படுத்தலாம்

### பாடநெறி வடிவமைப்பில்

தலையீட்டு வடிவமைப்பைக் கற்பிக்கும்போது repository-ஐ ஒரு குறிப்பாகப் பயன்படுத்துங்கள். மாணவர்களை:

1. அவர்கள் மாற்ற விரும்பும் ஒரு நடத்தையை அடையாளம் காணச் செய்யுங்கள்
2. பொருத்தமான நுட்பங்களுக்காக repository-ஐத் தேடச் செய்யுங்கள்
3. Strong vs. Emerging சான்று விருப்பங்களை ஒப்பிடச் செய்யுங்கள்
4. நிரப்பு நுட்பங்களின் கலவையைத் தேர்ந்தெடுக்கச் செய்யுங்கள்
5. தரப்படுத்தப்பட்ட BCT IDs-ஐப் பயன்படுத்தி தங்கள் தலையீட்டை எழுதச் செய்யுங்கள்

### பட்டறைகளில்

- **முன்-வாசிப்பு:** அமர்வுக்கு முன் ஒரு குறிப்பிட்ட வகையை உலாவ பங்கேற்பாளர்களுக்கு ஒதுக்குங்கள்
- **செயல்பாடு:** குழுக்களுக்கு ஒரு வழக்கு ஆய்வைக் கொடுத்து, அவர்களின் தலையீட்டு வடிவமைப்பிற்காக 3–5 BCTs-ஐத் தேர்ந்தெடுக்கச் செய்யுங்கள்
- **கலந்துரையாடல்:** குழுத் தேர்வுகளை ஒப்பிடுங்கள் — வெவ்வேறு குழுக்கள் ஏன் வெவ்வேறு நுட்பங்களைத் தேர்ந்தெடுத்தன?

### முன்மொழிவு எழுதுதலில்

முன்மொழிவுகளில் BCT taxonomy IDs-ஐக் குறிப்பிட பங்கேற்பாளர்களுக்குக் கற்பியுங்கள். நிதியளிப்பாளர்கள் சான்று-அடிப்படையிலான தலையீட்டு வடிவமைப்பை அதிகளவில் எதிர்பார்க்கிறார்கள், மேலும் குறிப்பிட்ட BCTs-ஐ மேற்கோள் காட்டுவது (எ.கா., "நாங்கள் BCT 1.1 இலக்கு நிர்ணயம் மற்றும் BCT 2.2 நடத்தை குறித்த பின்னூட்டம் ஆகியவற்றைப் பயன்படுத்துவோம்") கடுமையைக் குறிக்கிறது.

### Theory of Change உடன் இணைத்தல்

BCTs நேரடியாக Theory of Change-இன் "செயல்பாடுகள்" மற்றும் "வழிமுறைகள்" அடுக்குகளுடன் பொருந்துகின்றன. குறிப்பிட்ட நுட்பங்கள் குறிப்பிட்ட விளைவுகளை எவ்வாறு உந்துகின்றன என்பதைக் காட்ட, repository-ஐ Theory of Change Lab உடன் பயன்படுத்துங்கள்.

5. **பயனுள்ள நுட்பங்களைப் புத்தகக்குறியிடுங்கள்** — உங்கள் திட்டப் பகுதிக்காக ஒரு தொகுப்பை உருவாக்குங்கள்

## குறிப்புகள்

- **நிரப்பு நுட்பங்களை இணையுங்கள்.** திறம்பட நடத்தை மாற்றும் தலையீடுகள் பொதுவாக ஒன்றாக 3–7 BCTs-ஐப் பயன்படுத்துகின்றன, ஒன்றை மட்டும் அல்ல.
- **உங்கள் சூழலில் சான்றைச் சரிபார்க்கவும்.** உலகளவில் Strong சான்று கொண்ட ஒரு நுட்பத்திற்கு தென் ஆசிய அமைப்புகளில் வரம்புக்குட்பட்ட சான்று இருக்கலாம் — பொருத்தமான இடத்தில் repository இதைக் குறிக்கிறது.
- **taxonomy IDs-ஐ தொடர்ந்து பயன்படுத்தவும்.** முன்மொழிவுகள், M&E திட்டங்கள் அல்லது ஆராய்ச்சிக் கட்டுரைகளை எழுதும்போது, தெளிவுக்காகவும் ஒப்பிடுதலுக்காகவும் எப்போதும் பெயருடன் BCT ID-ஐச் சேர்க்கவும்.
- **பழக்கமானதிலிருந்து தொடங்குங்கள்.** நீங்கள் ஏற்கனவே "விழிப்புணர்வு பிரச்சாரங்கள்" செய்தால், அந்தப் பிரச்சாரங்கள் உண்மையில் எந்த BCTs-ஐப் பயன்படுத்துகின்றன என்பதைத் தேடுங்கள் — BCT 5.1 "சுகாதார விளைவுகள் பற்றிய தகவல்" போன்ற நுட்பங்களை நீங்கள் ஏற்கனவே பெயரிடாமல் பயன்படுத்துகிறீர்கள் என்பதை நீங்கள் கண்டறியலாம்.
