# Visualization Cookbook வழிகாட்டி

## Visualization Cookbook என்றால் என்ன?

Visualization Cookbook என்பது உற்பத்திக்குத் தயாரான Python குறியீட்டுடன் கூடிய ஒரு **கேள்வி-உந்துதல் வரைபடத் தேர்வுக் கருவியாகும்**. வரைபடத் தொகுப்புகளை உலாவி, உங்கள் தரவுக்கு எந்த வரைபட வகை பொருந்தும் என்று யூகிப்பதற்குப் பதிலாக, ஒரு எளிய கேள்விக்கு நீங்கள் பதிலளிக்கிறீர்கள் — "என் தரவு என்ன கதையைச் சொல்கிறது?" — மேலும் சரியான வரைபடத்துடன், உடனடியாக நகலெடுத்துப் பயன்படுத்தக்கூடிய செயல்படும் குறியீட்டைப் பெறுகிறீர்கள்.

இதில் வளர்ச்சிப் பணியின் மிகவும் பொதுவான தரவுக் கதைகளை உள்ளடக்கிய **14 வரைபட வகைகள்** உள்ளன.

**அணுகல்:** DevData Practice (Professional tier)-இன் ஒரு பகுதி — [Visualization Cookbook-ஐத் திறக்க](https://impactmojo-devdata-pro.netlify.app/charts.html)

## இது தீர்க்கும் சிக்கல்

வளர்ச்சி நிபுணர்கள் தரவு நிறைந்த அறிக்கைகள், முன்மொழிவுகள், மற்றும் விளக்கக்காட்சிகளை உருவாக்குகிறார்கள் — ஆனால் வரைபடங்கள் பெரும்பாலும் பலவீனமான பகுதியாக இருக்கின்றன. பொதுவான சிக்கல்கள்:

- **தவறான வரைபட வகை** — பட்டை வரைபடம் தெளிவாக இருக்கும் இடத்தில் வட்ட வரைபடத்தைப் பயன்படுத்துதல், அல்லது நேரத்தைக் காட்டாதபோது கோட்டு வரைபடத்தைப் பயன்படுத்துதல்
- **குழப்பமான காட்சிகள்** — ஒரு வரைபடத்தில் அதிக நிறங்கள், லேபிள்கள், அல்லது தரவுப் புள்ளிகள்
- **புதிதாகத் தொடங்குதல்** — ஒரே ஒரு நல்ல வரைபடத்தை உருவாக்க Excel இல் மணிநேரம் செலவிடுதல் அல்லது Python கற்க முயற்சித்தல்
- **சீரற்ற தரம்** — ஒவ்வொரு குழு உறுப்பினரும் வெவ்வேறாகத் தோன்றும் வரைபடங்களை உருவாக்குகிறார்

Visualization Cookbook இவற்றை முதலில் ஒரு கேள்வியைக் கேட்டு தீர்க்கிறது: **உங்கள் தரவு என்ன சொல்ல முயற்சிக்கிறது?**

## இது எவ்வாறு செயல்படுகிறது

### படி 1: உங்கள் தரவுக் கதையைத் தேர்ந்தெடுக்கவும்

ஒவ்வொரு வரைபடமும் ஆறு வகையான கேள்விகளில் ஒன்றுக்குப் பதிலளிக்கிறது:

| தரவுக் கதை | நீங்கள் என்ன காட்டுகிறீர்கள் | எடுத்துக்காட்டு |
|-----------|-------------------|---------|
| **ஒப்பீடு** | விஷயங்கள் ஒன்றுக்கொன்று எவ்வாறு வேறுபடுகின்றன | "எந்த மாவட்டத்தில் அதிக நோய்த்தடுப்பு விகிதம் உள்ளது?" |
| **பரவல்** | ஒரு வரம்பில் தரவு எவ்வாறு பரவியுள்ளது | "எங்கள் இலக்குப் பகுதியில் வீட்டு வருமானங்கள் எவ்வாறு பரவியுள்ளன?" |
| **உறவு** | இரண்டு மாறிகள் ஒன்றுக்கொன்று எவ்வாறு தொடர்புடையவை | "கல்விச் செலவுக்கும் கற்றல் விளைவுகளுக்கும் இடையே தொடர்பு உள்ளதா?" |
| **அமைப்பு** | ஒரு முழுமையை எது உருவாக்குகிறது | "எங்கள் வரவுசெலவுத் திட்டத்தின் எந்த விகிதம் ஒவ்வொரு திட்டப் பகுதிக்கும் செல்கிறது?" |
| **காலத் தொடர்** | காலப்போக்கில் ஏதோ ஒன்று எவ்வாறு மாறுகிறது | "கடந்த 10 ஆண்டுகளில் வளர்ச்சிக் குறைபாட்டின் பரவல் எவ்வாறு மாறியது?" |
| **இடவியல்** | புவியியல் முழுவதும் ஏதோ ஒன்று எவ்வாறு மாறுபடுகிறது | "எந்த மாநிலங்களில் அதிக வறுமை விகிதம் உள்ளது?" |

### படி 2: சரியான வரைபடத்தைப் பெறுங்கள்

உங்கள் தரவுக் கதையின் அடிப்படையில், Cookbook ஒன்று அல்லது அதற்கு மேற்பட்ட வரைபட வகைகளைப் பரிந்துரைத்து உங்களுக்குக் காட்டுகிறது:
- ஒரு **மாதிரி வரைபடம்** — அது எப்படி இருக்கிறது என்று நீங்கள் பார்க்கலாம்
- **எப்போது பயன்படுத்த வேண்டும்** — மற்றும் எப்போது பயன்படுத்தக்கூடாது
- matplotlib மற்றும் seaborn (நிலையான தரவு அறிவியல் நூலகங்கள்) பயன்படுத்தும் **உற்பத்திக்குத் தயாரான Python குறியீடு**

### படி 3: குறியீட்டைத் தழுவவும்

Python குறியீட்டை நகலெடுத்து, மாதிரித் தரவை உங்களுடையதால் மாற்றி, இயக்கவும். வரைபடம் வெளியீட்டுக்குத் தயாராக உள்ளது — சரியான லேபிள்கள், சுத்தமான வடிவமைப்பு, மற்றும் தொழில்முறை பாணி.

## எனக்கு Python தெரிந்திருக்க வேண்டுமா?

**அவசியமில்லை.** நீங்கள் Python குறியீட்டை இயக்க முடிந்தால் (அல்லது இயக்கக்கூடிய ஒரு சக ஊழியர் இருந்தால்) Cookbook மிகவும் பயனுள்ளதாக இருக்கும், ஆனால் குறியீட்டு அறிவு இல்லாமலும்:

- **வரைபடத் தேர்வு வழிகாட்டுதல் தனக்குத்தானே மதிப்புமிக்கது.** எந்த வரைபட வகையைப் பயன்படுத்துவது என்பதை அறிவது பாதிப் போர் — பின்னர் நீங்கள் வசதியாக உணரும் Excel, Google Sheets, அல்லது எந்தக் கருவியிலும் அதை உருவாக்கலாம்.
- **குறியீடு விளக்கக் குறிப்புகளுடன் உள்ளது.** ஒவ்வொரு வரியும் என்ன செய்கிறது என்பதைக் கருத்துகள் விளக்குகின்றன, எனவே அடிப்படை Python திறன் கொண்டவர் அதை மாற்றியமைக்கலாம்.
- **ImpactMojo-வின் Data & Technology courses அடிப்படைகளைக் கற்பிக்கின்றன.** தரவுக் காட்சிப்படுத்தலுக்காக Python கற்க விரும்பினால், Data Visualization foundational course-உடன் தொடங்குங்கள்.

## கல்வியாளர்கள் Cookbook-ஐ எவ்வாறு பயன்படுத்தலாம்

### தரவுக் காட்சிப்படுத்தல் பட்டறைகளுக்கு
"உங்கள் தரவுக் கதையைத் தேர்ந்தெடுங்கள்" கட்டமைப்பின் வழியாக பங்கேற்பாளர்களை அழைத்துச் செல்லுங்கள். அவர்களின் சொந்தத் தரவைக் கொண்டுவரச் சொல்லி, ஒரு வரைபட வகையைத் தேர்ந்தெடுப்பதற்கு முன் அது எந்தக் கதையைச் சொல்கிறது என்பதைக் கண்டறியச் சொல்லுங்கள்.

### அறிக்கை எழுதும் அமர்வுகளுக்கு
குழுக்கள் அறிக்கைகளைத் தயாரிக்கும்போது, வரைபடங்கள் பொருத்தமாகவும் தெளிவாகவும் இருப்பதை உறுதி செய்ய Cookbook-ஐப் பயன்படுத்துங்கள். ஆறு தரவுக் கதை வகைகள், அவர்கள் என்னைத் தெரிவிக்க முயற்சிக்கிறார்கள் என்பதைப் பற்றி குழுக்கள் சிந்திக்க உதவுகின்றன.

### வரைபட எழுத்தறிவைக் கற்பிக்க
பங்கேற்பாளர்கள் குறியீடு எழுதாவிட்டாலும், வரைபடங்களை விமர்சன ரீதியாகப் படிக்க Cookbook அவர்களுக்குக் கற்பிக்கிறது. "இந்த வரைபடம் எந்தத் தரவுக் கதையைச் சொல்கிறது? அந்தக் கதைக்கு இது சரியான வரைபட வகையா?"

## குறிப்புகள்

- **வரைபட வகையில் இருந்தல்ல, தரவுக் கதையில் இருந்து தொடங்குங்கள்.** "நான் ஒரு வட்ட வரைபடம் உருவாக்க விரும்புகிறேன்" என்பது தவறான தொடக்கப் புள்ளி. "எங்கள் வரவுசெலவுத் திட்டத்தின் எந்த விகிதம் ஒவ்வொரு திட்டத்திற்கும் செல்கிறது என்பதைக் காட்ட விரும்புகிறேன்" என்பது சரியானது.
- **குறைவே அதிகம்.** சிறந்த வரைபடங்கள் ஒரு விஷயத்தைத் தெளிவாகத் தெரிவிக்கின்றன. உங்கள் வரைபடத்துக்கு ஒரு பத்தி விளக்கம் தேவைப்பட்டால், அதை எளிமைப்படுத்துங்கள்.
- **தரவுக் காட்சிப்படுத்தல் குறித்த Handout-உடன் Cookbook-ஐப் பயன்படுத்துங்கள்.** ஹேண்ட்அவுட் கொள்கைகளை உள்ளடக்குகிறது; Cookbook செயல்படுத்தலை வழங்குகிறது.
