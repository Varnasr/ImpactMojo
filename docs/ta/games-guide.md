# Games வழிகாட்டி

## ImpactMojo Games என்றால் என்ன?

ImpactMojo **ஊடாடும் games** வழங்குகிறது, அவை மூலோபாய முடிவெடுத்தல் மற்றும் உருவகப்படுத்துதல் மூலம் வளர்ச்சி தொடர்பான கருத்துகளைக் கற்பிக்கின்றன. ஒவ்வொரு விளையாட்டையும் விளையாட 10–20 நிமிடங்கள் ஆகும், அது ஒரு குறிப்பிட்ட கருத்தை உள்ளடக்கியது — விளையாட்டுக் கோட்பாடு மற்றும் சந்தைத் தோல்விகள் முதல் காலநிலை நடவடிக்கை, பாலின சமத்துவம், பொது சுகாதாரம் மற்றும் டிஜிட்டல் நெறிமுறைகள் வரை.

இவை வினாடி வினாக்கள் அல்லது ஃபிளாஷ்கார்டுகள் அல்ல. இவை ஊடாடும் உருவகப்படுத்துதல்கள், அங்கு உங்கள் முடிவுகளுக்கு விளைவுகள் உள்ளன, மேலும் கருத்துகள் சொற்பொழிவை விட விளையாட்டின் மூலம் தெளிவாகின்றன.

அனைத்து games-ம் **இலவசம், உலாவி-சார்ந்தவை, எந்த உள்நுழைவும் தேவையில்லை**. அவை impactmojo.in-இல் `/Games/`-இல் சுய-ஹோஸ்ட் செய்யப்பட்டுள்ளன.

### MiroFish AI Agents

பொருளியல் games-இல் **MiroFish AI agents** உள்ளன — தனித்துவமான தென்னாசிய அடையாளங்கள், பின்னணிக் கதைகள் மற்றும் மூலோபாய ஆளுமைகளைக் கொண்ட AI-இயங்கும் எதிராளிகள். ஒவ்வொரு agent-க்கும் அவர்களின் முடிவுகளை வடிவமைக்கும் அளவீடு செய்யப்பட்ட ஆளுமைப் பண்புகள் (ஒத்துழைப்புச் சாய்வு, அபாயச் சகிப்புத்தன்மை, நினைவக எடை) உள்ளன. நீங்கள் ஒரு சீரற்ற எண் உருவாக்கிக்கு எதிராக விளையாடவில்லை — நடைமுறை NGO இயக்குநர் மீராவுடன் பேச்சுவார்த்தை நடத்துகிறீர்கள், இலட்சியவாத ஆராய்ச்சியாளர் அர்ஜுனுடன் விவாதிக்கிறீர்கள், அல்லது புத்திசாலித்தனமான கொள்முதல் அதிகாரி நந்தினிக்கு எதிராகப் போட்டியிடுகிறீர்கள்.

இந்த AI அமைப்பு ஒரு Supabase Edge Function மூலம் **பல-வழங்குநர் LLM பின்னடைவுச் சங்கிலியை** (DeepSeek → Groq → Gemini → Together → OpenAI) பயன்படுத்துகிறது. LLM வழங்குநர்கள் கிடைக்காதபோது, ஒரு உள்ளூர் ஆளுமை இயந்திரம் எடையிடப்பட்ட அனுமான முறைகளைப் பயன்படுத்தி முடிவுகளை உருவாக்குகிறது — எனவே games எப்போதும் வேலை செய்கின்றன, ஆஃப்லைனிலும் கூட.

AI அமைப்பின் தொழில்நுட்ப விவரங்களுக்கு [Game Agents documentation](game-agents.md) பார்க்கவும்.

### இந்திய நாட்டுப்புற கலை கதை விளக்கப்படங்கள்

ஒவ்வொரு விளையாட்டிலும் **அசல் இந்திய நாட்டுப்புற கலை** ஆறு பாரம்பரிய பாணிகளில் இன்லைன் SVG-களாக வழங்கப்படுகிறது:

| **Madhubani** | பீகார் — தடித்த வெளிக்கோடுகள், பிரகாசமான நிரப்புதல்கள், இயற்கை வடிவங்கள் | Gender Equity, Econ Concepts, Real Middle India |

ஒவ்வொரு விளையாட்டிலும் அடங்கியவை:
- **கதை அறிமுகத் திரை** — கதையாடல் சூழலை அமைக்கும் முழுத்திரை நாட்டுப்புற கலைக் காட்சி
- **விளையாட்டின் இடைப்பட்ட இடைவேளைகள்** — சுற்றுகளுக்கு இடையில் உங்கள் தேர்வுகளுக்குப் பதிலளிக்கும் கலையும் கதையாடலும்
- **தகவமைப்பு முடிவுக் கலை** — உங்கள் ஒட்டுமொத்தச் செயல்திறனின் அடிப்படையில் வெவ்வேறு விளக்கப்படங்கள்

இந்தக் கலை ஒவ்வொரு விளையாட்டையும் தென்னாசிய காட்சி கலாச்சாரத்தில் அடித்தளமிடுகிறது, அதே நேரத்தில் கதை சொல்லல் மூலம் சுருக்கக் கருத்துகளைத் தொட்டுணரக்கூடியதாக மாற்றுகிறது.

## கல்வியாளர்கள் Games-ஐ எவ்வாறு பயன்படுத்தலாம்

### பட்டறைத் தொடக்கங்களாக

ஒரு கருத்தை அனுபவ ரீதியாக அறிமுகப்படுத்த அமர்வின் தொடக்கத்தில் ஒரு விளையாட்டை விளையாடுங்கள். நீங்கள் கோட்பாட்டை விளக்குவதற்கு *முன்* பங்கேற்பாளர்கள் கருத்துடன் ஈடுபடுகிறார்கள் — இது ஆர்வத்தை உருவாக்குகிறது மற்றும் விவாதத்திற்கு அவர்களுக்கு ஒரு பகிரப்பட்ட குறிப்புப் புள்ளியை வழங்குகிறது.

**எடுத்துக்காட்டு ஓட்டம்:**
1. Public Good Game-ஐ விளையாடுங்கள் (10 நிமிடங்கள்)
2. மீள்பார்வை: "என்ன நடந்தது? பங்களிப்புகள் ஏன் குறைந்தன?" (10 நிமிடங்கள்)
3. பொதுச் சரக்குகள் மற்றும் இலவசப் பயணம் என்ற முறையான கருத்தை அறிமுகப்படுத்துங்கள் (15 நிமிடங்கள்)
4. அவர்களின் திட்டங்களில் நிஜ-உலக பயன்பாடுகளைப் பற்றி விவாதியுங்கள் (15 நிமிடங்கள்)

### வகுப்பறை செயல்பாடுகளாக

குழு விளையாட்டுக்காகத் திரையில் காட்டப்படும்போது games நன்றாக வேலை செய்கின்றன. வகுப்பை முடிவுகள் மீது ஒன்றாக வாக்களிக்கச் செய்யுங்கள், அல்லது அணிகளாகப் பிரித்து விளைவுகளை ஒப்பிடுங்கள்.

**நல்ல ஜோடிகள்:**
- Public Good Game + Commons Crisis = கூட்டுச் செயலின் விரிவான பார்வை
- Information Asymmetry + Externality = சந்தைத் தோல்விகளை ஒன்றாகப் புரிந்துகொள்ளுதல்
- Prisoners' Dilemma + Cooperation Paradox = மூலோபாய சிந்தனையில் ஆழமான பார்வை

### சுய-படிப்பு பணிகளாக

ஒரு பட்டறைக்கு முன் முன்-வேலையாக 2–3 games-ஐ ஒதுக்குங்கள். பங்கேற்பாளர்களை ஒரு பத்திச் சிந்தனை எழுதச் சொல்லுங்கள்: "உங்களை என்ன ஆச்சரியப்படுத்தியது? இந்தக் கருத்து உங்கள் பணியில் எப்படித் தோன்றுகிறது?"

### மீள்பார்வை விவாதங்களுக்கு

எந்த விளையாட்டிற்குப் பிறகும், இந்தக் கேள்விகள் நன்றாக வேலை செய்கின்றன:
- நீங்கள் என்ன உத்தியைப் பயன்படுத்தினீர்கள்? அது சுற்றுகளுக்கு இடையில் மாறியதா?
- விளைவைப் பற்றி உங்களை என்ன ஆச்சரியப்படுத்தியது?
- உங்கள் வளர்ச்சிப் பணியில் இந்த இயக்கவியலை எங்கே காண்கிறீர்கள்?
- எந்த வழிமுறைகள் விளைவை மாற்றக்கூடும்?

## குறிப்புகள்

- **Games பெரியவர்களுக்காக வடிவமைக்கப்பட்டவை, குழந்தைகளுக்காக அல்ல.** சட்டகம், மொழி மற்றும் சிக்கல்தன்மை வளர்ச்சித் துறை வல்லுநர்கள் மற்றும் பல்கலைக்கழக மாணவர்களின் மட்டத்தில் அமைக்கப்பட்டுள்ளன.
- **மீள்பார்வையே கற்றல் நிகழும் இடம்.** விளையாட்டே அனுபவத்தை உருவாக்குகிறது; அதற்குப் பிந்தைய விவாதம் புரிதலை உருவாக்குகிறது. மீள்பார்வைக்கு எப்போதும் நேரத்தை ஒதுக்குங்கள்.
- **பல சுற்றுகளை விளையாடுங்கள்.** பங்கேற்பாளர்கள் தங்கள் உத்திகளைச் சரிசெய்வதால் பெரும்பாலான games இரண்டாவது மற்றும் மூன்றாவது விளையாட்டுகளில் ஆழமான இயக்கவியலை வெளிப்படுத்துகின்றன.
- **நிஜ திட்டங்களுடன் இணைக்கவும்.** Commons Crisis Game-ஐ விளையாடிய பிறகு கேளுங்கள்: "உங்கள் WASH திட்டத்தில் பொது வளப் பிரச்சினையை எங்கே காண்கிறீர்கள்?" இந்த மாற்றுப் படிநிலை அவசியம்.
